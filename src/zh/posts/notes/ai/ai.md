# AI 笔记导览

这个页面不承载知识本身，它只回答两件事：**遇到问题该翻哪一份笔记**，以及**几份笔记之间的边界在哪**。边界写清楚，以后新增内容才不会写重。

## 五份笔记各自回答什么

| 笔记 | 层次 | 一句话定位 |
|---|---|---|
| [数学基础](./math.md) | 工具层 | 机器学习用到的数学：证明方法、微积分、概率统计、线性代数，以及最小二乘这条把它们串起来的线 |
| [机器学习](./ml.md) | 模型层 | 模型与算法本身：假设空间、损失、优化、泛化，经典算法到神经网络 |
| [人工智能](./ai-intro.md) | 符号推理层 | 搜索、约束满足、对抗搜索、逻辑与知识表示、概率推理，以及 NLP 从词向量到预训练 |
| [LLM 应用工程](./ai-swe/01-llm.md)（`ai-swe/`） | 系统层 | 把大模型做成系统：Prompt、RAG、Agent、工具与协议、评估、微调、多模态 |
| [知识图谱](./knowledge-graph.md) | 结构化知识层 | 图与本体、知识抽取、表示学习、基于图谱的检索与问答 |

## 边界判据

新增内容时先过这几个问题，答案决定它写进哪一份笔记：

| 判据问题 | 去处 |
|---|---|
| 去掉模型与工程语境之后，它还是一个完整的定义 / 定理 / 推导吗？ | 数学基础 |
| 它在讲某个**模型或算法本身**：假设是什么、在优化什么、为什么有效？ | 机器学习 |
| 它在讲**符号推理**：搜索、逻辑、概率图模型？ | 人工智能 |
| 它在讲**怎么用模型搭系统**：编排、检索、工具、评估、部署？ | LLM 应用工程 |
| 它在讲**图结构化的知识**：本体、抽取、图查询？ | 知识图谱 |

同一个名词出现在两份笔记里不算重复，只要角色不同：数学讲定义与性质，机器学习讲模型与算法，工程笔记讲使用与工程边界。
