## 边界判据

新增内容时先过这几个问题，答案决定它写进哪一份笔记：

| 判据问题 | 去处 |
|---|---|
| 去掉模型与工程语境之后，它还是一个完整的定义 / 定理 / 推导吗？ | 数学基础 |
| 它在讲某个**模型或算法本身**：假设是什么、在优化什么、为什么有效？ | 机器学习 |
| 它在讲**网络结构、训练机制、规模与推理约束**，且不绑定具体语言对象？ | 深度学习 |
| 它在讲**语言的结构、分词、词表示、语言模型、语境化表示或 NLP 任务**？ | 自然语言处理 |
| 它在讲**符号推理**：搜索、逻辑、概率图模型？ | 人工智能 |
| 它在讲**怎么用模型搭系统**：编排、检索、工具、评估、部署？ | LLM 应用工程 |
| 它在讲**图结构化的知识**：本体、抽取、图查询？ | 知识图谱 |

同一个名词出现在两份笔记里不算重复，只要角色不同：数学讲定义与性质，机器学习讲模型与算法，深度学习讲结构与训练，NLP 讲语言对象与任务，工程笔记讲使用与工程边界。
