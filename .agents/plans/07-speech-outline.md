## 1. 主线与边界

**主线**：一段波形如何被切成帧、变成特征，被模型读成文字、说话人或事件，又如何被合成回波形；每一层做了什么假设、丢掉了什么。

**边界**：

- 网络结构（卷积、RNN、注意力、Transformer、量化）在深度学习笔记，本文只取"声学模型怎么用它们"。
- 文本侧（分词、子词、语言模型、序列标注）在 NLP 笔记，本文只讲"语音与文本的接口"。
- 语音大模型的 Prompt、RAG、Agent 用法在 LLM 应用工程笔记；本文只讲语音编码器与接口。
- 数学工具在数学笔记；**信号处理与动态规划**两块目前没有归属，本文自建（见第 3 节）。

## 3. 六章大纲

### 一、语音信号与特征：从波形到频谱图
- **读者问题**：声音怎么变成模型能吃的矩阵？为什么是频谱图而不是波形？
- **承接**：全篇起点；后面所有模型都吃同一套特征。
- **必讲**：发音与源—滤波器模型；音素、音位、协同发音与韵律；采样、量化、混叠；预加重、分帧、加窗；DFT/STFT 与频谱图；mel 滤波器组、MFCC、fbank；dB 与动态范围；fbank 与 MFCC 的选择。
- **可选/删除**：MFCC 的 DCT 逐行推导；听觉心理声学。
- **H3**：
  1. 发音与声学：源—滤波器模型
  2. 音素、音位与韵律
  3. 采样、量化与混叠
  4. 分帧、加窗与短时傅里叶
  5. mel 滤波器组与 MFCC
  6. 特征的选择：fbank、MFCC 与原始波形

### 二、识别：从 GMM-HMM 到端到端 ASR
- **读者问题**：一段音频怎么变成一串字？传统流水线与端到端模型各自解决了什么？
- **承接**：吃第一章的特征；为第五章的预训练模型提供任务定义与指标。
- **必讲**：任务定义与 WER/CER；GMM-HMM 声学模型、发音词典、语言模型与解码；Viterbi 与 beam search；DNN-HMM 混合系统；CTC 的 blank、折叠与前后向；RNN-T 的联合网络与对齐格；注意力编码器—解码器；Conformer；SpecAugment 与数据增强；流式与非流式。
- **可选/删除**：Kaldi 的配方细节；WFST 解码图的构造。
- **边界**：口音、噪声、领域漂移；流式与准确率的取舍。
- **H3**：
  1. 任务与指标：WER 与 CER
  2. GMM-HMM：声学模型、词典与语言模型
  3. 解码：Viterbi 与 beam search
  4. CTC：blank、折叠与前后向
  5. RNN-T 与注意力编码器—解码器
  6. Conformer 与训练技巧
  7. 边界：流式、口音、噪声与领域

### 三、合成：文本前端、声学模型与声码器
- **读者问题**：文字怎么变成声音？为什么 TTS 要拆成前端、声学模型和声码器三段？
- **承接**：与第二章对称——一个把语音变成文字，一个把文字变成语音。
- **必讲**：文本规范化、分词、注音（G2P）；韵律、停延与时长；Tacotron 的自回归声学模型；FastSpeech 的非自回归与时长预测；VITS 的端到端；声码器 WaveNet、HiFi-GAN；MOS、可懂度与 RTF；单说话人、多说话人与少样本。
- **可选/删除**：声码器的完整网络结构；扩散 TTS 的采样推导。
- **边界**：韵律与情感的评估主观性；数据质量决定音质上限。
- **H3**：
  1. 文本前端：规范化、分词与注音
  2. 韵律、停延与时长
  3. 声学模型：Tacotron、FastSpeech 与 VITS
  4. 声码器：WaveNet 与 HiFi-GAN
  5. 评测：MOS、可懂度与 RTF
  6. 边界：单说话人、少样本与情感

### 四、增强、分离与说话人
- **读者问题**：真实录音有噪声、混响、多人同时说话，前端怎么把目标声音捞出来？谁在说话怎么判断？
- **承接**：吃第一章的声学；为第二章提供鲁棒输入，为第六章提供端侧功能面。
- **必讲**：噪声、混响、回声与多说话人的问题定义；SNR 与 RT60；谱减、Wiener 滤波；波束成形；掩码与深度增强（IBM/IRM、Conv-TasNet）；语音分离；说话人 embedding（x-vector、ECAPA）、验证与 EER、日志（分段+聚类）；VAD 与 KWS。
- **可选/删除**：麦克风阵列的阵列流形推导；音乐分离。
- **边界**：增强会引入失真，识别收益不等于听感收益；分离的天花板由混叠决定。
- **H3**：
  1. 问题定义：噪声、混响、回声与多说话人
  2. 传统方法：谱减、Wiener 与波束成形
  3. 掩码与深度增强
  4. 语音分离：鸡尾酒会问题
  5. 说话人：embedding、验证与日志
  6. 小任务：VAD 与 KWS

### 五、自监督预训练与 Whisper 范式
- **读者问题**：没有标注数据时，语音模型怎么学表示？Whisper 为什么能跨语言、跨任务？
- **承接**：吃第二章的任务与第四章的鲁棒性；把"预训练 + 微调"这条线接到语音上。
- **必讲**：自监督的三种目标（对比、聚类、掩码预测）；wav2vec 2.0 的量化与对比损失；HuBERT 的离线聚类目标；WavLM 的掩码建模；Whisper 的弱监督、多任务与 30 秒窗口；语音大模型的接口；低资源与多语言。
- **可选/删除**：data2vec 的蒸馏细节；各模型的榜单对比。
- **边界**：自监督学到的表示对什么任务有效；Whisper 的窗口与时间戳限制。
- **H3**：
  1. 自监督的目标：对比、聚类与掩码预测
  2. wav2vec 2.0 与 HuBERT
  3. Whisper：弱监督与多任务
  4. 语音大模型：音频编码器与文本解码器
  5. 低资源与多语言
  6. 边界：数据、算力与评测

### 六、部署：流式、量化与端侧引擎
- **读者问题**：模型训好之后，怎么在手机、浏览器、树莓派上跑起来？延迟、内存、准确率怎么取舍？
- **承接**：吃第二章的流式与第四章的 VAD/说话人；把前五章的模型落到可运行的系统。
- **必讲**：流式的 chunk 与 lookahead；首字延迟与 RTF；int8 量化与 ggml/gguf、ONNX；sherpa-onnx 的功能面（ASR/TTS/VAD/说话人/KWS/增强/分离）与模型导出；whisper.cpp 的 30 秒窗口、VAD 拼接与 Metal/CoreML；端侧与云的取舍；评测方法。
- **可选/删除**：具体芯片的算子优化；服务化部署（归 ai-swe）。
- **边界**：端侧的内存与功耗；量化对长尾识别的影响；隐私与合规。
- **H3**：
  1. 流式：chunk、lookahead 与延迟
  2. 量化：int8、ggml 与 ONNX
  3. sherpa-onnx：功能面与模型导出
  4. whisper.cpp：窗口、VAD 拼接与硬件后端
  5. 指标：RTF、内存与首字延迟
  6. 边界：端侧与云的取舍
