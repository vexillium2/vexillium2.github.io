软件设计学习笔记

全文主线只有一句：软件设计的本质是管理复杂度。八章按"为什么（Why）→ 用什么决策（Principles）→ 怎么切分（Structure）→ 运行时如何运转（Runtime）→ 经典方案（Patterns）→ 如何演进（Process）→ 跨语言审视（Lens）→ 如何持续修炼（Meta）"推进。各章可独立阅读，但前两章是后面所有取舍的判据来源。

这是所有软件设计的元问题。不讲清复杂度从哪来、为何增长，后面的模式与原则只是没有判据的招式堆砌。

代码评审（Code Review）

定位

CR 的目的不是挑错，而是集体提升代码质量 + 知识共享，让 PR 保持干净和清晰。 核心原则：你 PR 的代码，最终 owner 还是你——AI 可以辅助，但看懂、负责是你的事。

  • 上游：api-dev（API 开发）

IDE快捷键

Windows

  • 查找所有引用 Alt + F7

  • shift+F6 重构

  • ctrl + shift + r 全局替换

  • ctrl + p 查看函数/方法参数

  • Ctrl + q 弹出一个包含 Javadoc 或源代码注释的窗口，提供函数的详细描述、参数、返回值等。

  • Ctrl + Shift + I 不跳转，直接在小窗口中查看类、方法或字段的定义。

  • Ctrl + B / Ctrl + 鼠标左键 跳转到类、方法或变量的定义位置。

  • ctrl + h 查看该接口实现类

  • ctrl + F12 查看类中所有方法

  • ctrl+alt+l 格式化代码块

  • ctrl+alt+o 优化导入

  • ctrl+alt+v 生成一个变量替换

  • ctrl+x把这一行剪切

  • ctrl+shift+"-" 收起所有方法

  • alt + insert 创建构造方法

  • alt + enter 测试、实现类

  • alt + ⬅ 切换标签页
