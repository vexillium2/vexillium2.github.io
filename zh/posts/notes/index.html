IDE快捷键

Jetbrains

Windows

  • 查找所有引用 Alt + F7

  • shift+F6 重构

  • ctrl + shift + r 全局替换

  • ctrl + p 查看函数/方法参数

  • Ctrl + q 弹出一个包含 Javadoc 或源代码注释的窗口，提供函数的详细描述、参数、返回值等。

  • Ctrl + Shift + I 不跳转，直接在小窗口中查看类、方法或字段的定义。

  • Ctrl + B / Ctrl + 鼠标左键 跳转到类、方法或变量的定义位置。

  • ctrl + h 查看该接口实现类

  • ctrl + F12 查看类中所有方法

  • ctrl+alt+l 格式化代码块

  • ctrl+alt+o 优化导入

  • ctrl+alt+v 生成一个变量替换

  • ctrl+x把这一行剪切

  • ctrl+shift+"-" 收起所有方法

  • alt + insert 创建构造方法

  • alt + enter 测试、实现类

  • alt + ⬅ 切换标签页
