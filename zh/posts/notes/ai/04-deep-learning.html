深度学习：从反向传播到 Transformer

vexillium2026/10/12大约 51 分钟人工智能深度学习

写在前面

深度学习的材料最不缺，缺的是"从一次迭代讲起"的顺序。这份笔记的顺序是照着李沐的《动手学深度学习》、CS231n 的讲义和 Karpathy 的 nanoGPT 排的：先让一个最小的网络跑通，再问它为什么能训得动。

我建议你至少手算一次反向传播，哪怕只是两层、四个数。算过之后，梯度消失、初始化、残差这些词才不再是口号。Transformer 也不要一上来读论文，先把注意力当成"用查询去加权一组值"，跑一个几十行的小例子，再回头看 QKV。

表示学习：深度学习替代了什么

传统机器学习的流程是"人工设计特征，再套一个分类器"。深度学习把前一半也交给模型。这一章回答两件事：手工特征到底败在哪，以及什么样的任务根本不值得用深度网络。

手工特征：HOG、SIFT 与词袋的两个失效点

定义

手工特征是由人根据领域知识设计的输入变换：HOG 统计局部梯度方向直方图，SIFT 提取尺度不变的关键点描述子，词袋（BoW）把文本表示成词频向量。

性质（失效点一：线性不可分）

手工特征的质量决定分类器的上限。特征设计得好，线性分类器就够用；设计得不好，换多复杂的分类器都救不回来。异或问题是最小的例子：两个特征 x1,x2x_1, x_2x1​,x2​ 上，正类在 (0,1)(0,1)(0,1) 与 (1,0)(1,0)(1,0)，负类在 (0,0)(0,0)(0,0) 与 (1,1)(1,1)(1,1)，任何直线都分不开。加一个特征 x1x2x_1 x_2x1​x2​ 之后，问题立刻线性可分。

性质（失效点二：领域经验无法迁移）

HOG 为行人检测调参，换到医学影像就失效；SIFT 假设局部纹理稳定，换到文本就没有对应物。每换一个领域，特征工程要重做一遍，而且依赖专家的隐性知识。特征的可迁移性，比单个特征的好坏更重要。

注意

  • 手工特征不是"落后技术"。数据少、可解释性要求高、算力受限时，它仍然是正确选择。
  • 深度学习的优势不在"自动"两个字，而在特征与分类器联合优化：特征朝着降低任务损失的方向被学习，而不是朝着"看起来合理"的方向被设计。

小结

手工特征的两个失效点——表达力受限于设计者、经验不可迁移——构成了表示学习的动机。深度学习要做的，是把特征也变成可训练的参数。

线性可分性：特征问题还是模型问题

性质

一个数据集在某个特征空间里线性可分，不说明它"本质上简单"，只说明当前表示把类别分开了。核方法通过在隐式高维空间里做内积来换表示，神经网络通过多层非线性变换来换表示，两者解决的是同一个问题。

例

同心圆数据在二维平面上线性不可分，映射到 (x12,x22)(x_1^2, x_2^2)(x12​,x22​) 之后就线性可分了。这个映射是人工选的；神经网络把映射本身也参数化，用梯度下降去学。

注意

"模型不够复杂"和"特征不够好"经常被混为一谈。判断方法：看训练误差。训练误差高，说明表示或容量不足；训练误差低而验证误差高，才是泛化问题。

小结

线性可分性是一个关于表示的性质，不是关于数据本质的性质。深度学习改的是表示，不是分类器。

分层表示：底层通用、顶层判别

性质

深层网络逐层变换输入：底层学到边缘、纹理、局部模式，中层组合成部件，顶层组合成任务相关的语义。层的深度提供了组合的层级，这是浅层模型没有的。

例

图像分类网络的第一层卷积核常表现为边缘检测器，中间层响应眼睛、轮子这类部件，高层响应整只猫或整辆车。文本网络底层学到词形与局部搭配，高层学到句法角色与语义类别。

注意

  • 分层不是深度学习独有的。核方法也能构造高阶特征，只是层级是人工指定的，而且通常只有一两层。
  • "底层通用、顶层判别"是经验观察，不是定理。迁移学习利用的正是这一点：底层可以冻结，顶层需要重训。

小结

深度带来的是组合的层级：简单模式组合成复杂模式，复杂模式再组合成任务概念。这是"深"相对于"宽"的核心优势。

三种范式：预训练微调、监督训练与自监督

性质（三次更替）

  • 2006：无监督预训练 + 微调。用自编码器逐层初始化，缓解深层网络难以训练的问题。算力与数据都有限，预训练是为了"训得动"。
  • 2012：大规模监督训练。ImageNet 提供了百万级标注，ReLU、Dropout、GPU 让深层网络端到端可训。预训练不再是必需品。
  • 2015 之后：自监督预训练。用数据本身构造监督信号（预测被遮住的词、对比不同视图），再微调或零样本使用。标注不再是瓶颈，数据规模成为瓶颈。

注意

  • "有监督/无监督"描述的是训练范式，不是模型结构。同一个网络可以先自监督预训练，再有监督微调。
  • 自监督不是"没有标签"，而是标签从数据本身生成。它的上限由预训练任务与数据分布共同决定。

小结

三次更替解决的是不同瓶颈：训不动、没数据、标注太贵。深度学习的历史不是模型越来越复杂，而是监督信号的来源在不断变化。

边界：什么时候不值得用深度网络

性质（四个判据）

  1. 数据量：标注样本少于几千时，树模型或线性模型往往更稳。
  2. 任务结构：表格数据、强业务规则、需要逐条解释的决策，深度网络没有优势。
  3. 成本：训练与推理的算力、延迟、显存约束。实时系统里，一个小模型比一个大模型更合适。
  4. 可维护性：深度模型的错误难以定位，特征与规则的组合可以逐条审计。

注意

  • "深度网络效果更好"通常是在大数据 + 高维非结构化输入的条件下成立。离开这个条件，结论会反转。
  • 先用简单模型建立基线，再决定是否上深度模型。没有基线的深度模型，无法判断收益来自模型还是来自数据。

小结

深度网络是一种用数据与算力换表示的方法。数据、算力、任务结构任一不满足时，它不是默认选项。

计算图与反向传播：一次训练迭代

这一章把模型拆成节点与边，回答一个具体问题：一次 mini-batch 迭代里，每个参数到底收到了什么信号、按什么顺序更新。

神经元、多层结构与矩阵表示

定义

单个神经元是"线性组合 + 非线性"：

z=w⊤x+b,a=f(z)z = w^{\top}x + b, \qquad a = f(z) z=w⊤x+b,a=f(z)

www 是权重，bbb 是偏置，fff 是激活函数。一层神经元并排，就得到

z=Wx+b,a=f(z)z = Wx + b, \qquad a = f(z) z=Wx+b,a=f(z)

W∈Rdout×dinW \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}W∈Rdout​×din​。

性质（批量化）

把 nnn 个样本按行堆成 X∈Rn×dinX \in \mathbb{R}^{n \times d_{\text{in}}}X∈Rn×din​，前向写成

Z=XW⊤+1b⊤,A=f(Z)Z = XW^{\top} + \mathbf{1}b^{\top}, \qquad A = f(Z) Z=XW⊤+1b⊤,A=f(Z)

结果的第 0 维始终是 batch，这是深度学习代码里所有张量形状的约定来源。

例

输入 4 维、隐藏层 3 个神经元：WWW 是 3×43 \times 43×4，bbb 是 3 维，参数量 3×4+3=153 \times 4 + 3 = 153×4+3=15。batch 为 32 时，XXX 是 32×432 \times 432×4，ZZZ 是 32×332 \times 332×3。

注意

  • 偏置可以吸收进权重：给 xxx 补一个恒为 1 的分量，bbb 就并进 www。公式更短，但代码里通常分开写，便于初始化。
  • 参数量与 batch 无关。batch 只影响计算并行度与梯度噪声，不影响模型容量。

把形状约定写成代码：一个 batch 的输入是 (N,din)(N, d_{\text{in}})(N,din​)，权重是 (dout,din)(d_{\text{out}}, d_{\text{in}})(dout​,din​)，偏置在最后一维广播。

import torch

torch.manual_seed(0)
x = torch.randn(3, 4)            # (N, d_in) = (3, 4)
w = torch.randn(3, 4)            # (d_out, d_in) = (3, 4)
b = torch.randn(3)               # (d_out,)

z = x @ w.T + b                  # (3, 4) @ (4, 3) -> (3, 3)
print(z.shape)                   # torch.Size([3, 3])
print(b.expand_as(z).shape)      # 广播不复制数据，只在计算时对齐

代码里的转置不是装饰：PyTorch 的线性层把权重存成 (dout,din)(d_{\text{out}}, d_{\text{in}})(dout​,din​)，所以前向要写 xW⊤xW^{\top}xW⊤，而不是 WxWxWx。形状对不上时，报错信息里的两个尺寸就是这两个约定。

小结

一层网络就是一次仿射变换加一次逐元素非线性。深与浅的差别，在于这样的变换叠了几次。

计算图与全连接层

定义

计算图把前向计算表示成有向无环图：节点是张量或运算，边是依赖关系。前向传播按拓扑序求值，反向传播按逆拓扑序求梯度。

性质（局部梯度）

每个运算只需要知道自己的局部导数。链式法则把上游梯度与本节点的局部导数相乘，结果传给下游。反向传播不是新数学，而是链式法则在计算图上的机械执行。

例

z=x⋅yz = x \cdot yz=x⋅y 的局部导数是 ∂z/∂x=y\partial z/\partial x = y∂z/∂x=y、∂z/∂y=x\partial z/\partial y = x∂z/∂y=x。上游梯度 ggg 到达时，xxx 收到 g⋅yg \cdot yg⋅y，yyy 收到 g⋅xg \cdot xg⋅x。乘法节点在前向时缓存两个输入，反向时直接使用。

注意

  • 计算图不唯一。同一个函数可以拆成不同的节点粒度，粒度越细，局部导数越简单，但图越大。
  • 前向必须保存反向需要的中间量（激活值、掩码）。显存占用主要来自这些缓存，不是参数本身。

计算图不是比喻：每个张量都记着自己由谁算出，梯度只在 requires_grad 为真的路径上传播。

import torch

x = torch.tensor([2.0], requires_grad=True)
y = torch.tensor([3.0], requires_grad=True)
z = x * y + x                 # z = xy + x
z.retain_grad()               # 非叶节点的梯度默认不保留
z.backward()

print(x.grad)                 # dz/dx = y + 1 = 4
print(y.grad)                 # dz/dy = x = 2
print(z.grad)                 # 1.0：输出节点的梯度

w = (x * 2).detach()          # detach 切断梯度，w 不再追踪 x
print(w.requires_grad)        # False

detach 与 no_grad 的区别在用途：detach 造一个不带梯度的张量，no_grad 让一段计算不建图。前者常用于冻结目标、截断时间反向传播；后者用于推理与参数更新。

小结

计算图把"求导"变成了"按图传播"。框架自动微分的全部工作，就是记录前向、按逆序调用局部导数。

softmax 与交叉熵：组合梯度为什么这么干净

定义

softmax 把 KKK 个实数得分变成概率分布：

pi=exp⁡(zi)∑j=1Kexp⁡(zj)p_i = \frac{\exp(z_i)}{\sum_{j=1}^{K}\exp(z_j)} pi​=∑j=1K​exp(zj​)exp(zi​)​

交叉熵损失（标签 yyy 是 one-hot）：

ℓ=−∑i=1Kyilog⁡pi=−log⁡py\ell = -\sum_{i=1}^{K} y_i \log p_i = -\log p_y ℓ=−i=1∑K​yi​logpi​=−logpy​

推导（组合梯度）

先对 ziz_izi​ 求导。分两种情况：

∂pi∂zj={pi(1−pi),i=j−pipj,i≠j\frac{\partial p_i}{\partial z_j} = \begin{cases} p_i(1 - p_i), & i = j \\ -p_i p_j, & i \ne j \end{cases} ∂zj​∂pi​​={pi​(1−pi​),−pi​pj​,​i=ji=j​

再对损失求导。因为 yyy 是 one-hot，只有 i=yi = yi=y 的项非零：

∂ℓ∂zj=−1py∂py∂zj\frac{\partial \ell}{\partial z_j} = -\frac{1}{p_y}\frac{\partial p_y}{\partial z_j} ∂zj​∂ℓ​=−py​1​∂zj​∂py​​

当 j=yj = yj=y 时，−1py⋅py(1−py)=py−1-\frac{1}{p_y} \cdot p_y(1 - p_y) = p_y - 1−py​1​⋅py​(1−py​)=py​−1；当 j≠yj \ne yj=y 时，−1py⋅(−pypj)=pj-\frac{1}{p_y} \cdot (-p_y p_j) = p_j−py​1​⋅(−py​pj​)=pj​。合起来：

∂ℓ∂z=p−y\frac{\partial \ell}{\partial z} = p - y ∂z∂ℓ​=p−y

性质

梯度就是"预测减标签"。预测正确时梯度为零，预测越错梯度越大；所有分量的梯度之和为零，因为 ppp 与 yyy 都归一化。

注意

  • 这个简洁形式只对"softmax + 交叉熵"成立。换成 softmax + MSE，梯度里会多出一个 (p−y)(p - y)(p−y) 之外的因子，训练明显变慢。
  • 数值上要先用 log-sum-exp 稳定化再取对数，不要先算 ppp 再取 log⁡p\log plogp：ppp 很小时会下溢成 0，log⁡0\log 0log0 变成负无穷。

小结

softmax 与交叉熵是一对：单独求导都很繁，组合起来只剩 p−yp - yp−y。这是分类任务默认用这一对损失的原因。

反向传播：一次 mini-batch 的完整回路

定义

对一个 LLL 层网络，记第 lll 层的预激活为 zlz^lzl、激活为 ala^lal，损失为 ℓ\ellℓ。定义误差信号

δl=∂ℓ∂zl\delta^l = \frac{\partial \ell}{\partial z^l} δl=∂zl∂ℓ​

推导（递推）

输出层：

δL=p−y\delta^L = p - y δL=p−y

相邻层之间，由链式法则：

δl=(Wl+1)⊤δl+1⊙f′(zl)\delta^l = \left(W^{l+1}\right)^{\top}\delta^{l+1} \odot f'(z^l) δl=(Wl+1)⊤δl+1⊙f′(zl)

参数梯度：

∂ℓ∂Wl=δl(al−1)⊤,∂ℓ∂bl=δl\frac{\partial \ell}{\partial W^l} = \delta^l \left(a^{l-1}\right)^{\top}, \qquad \frac{\partial \ell}{\partial b^l} = \delta^l ∂Wl∂ℓ​=δl(al−1)⊤,∂bl∂ℓ​=δl

性质（计算顺序）

前向保存每层的 zlz^lzl、ala^lal；反向从 δL\delta^LδL 出发，逐层回传，边回传边算参数梯度。一次迭代的复杂度与前向同阶，常数约为两到三倍。

例（一个两层网络）

输入 x∈R4x \in \mathbb{R}^4x∈R4，隐藏层 3 个 ReLU，输出 2 类。前向：z1=W1x+b1z^1 = W^1 x + b^1z1=W1x+b1，a1=ReLU(z1)a^1 = \mathrm{ReLU}(z^1)a1=ReLU(z1)，z2=W2a1+b2z^2 = W^2 a^1 + b^2z2=W2a1+b2，p=softmax(z2)p = \mathrm{softmax}(z^2)p=softmax(z2)。若真实标签是第 2 类，y=(0,1)y = (0, 1)y=(0,1)，p=(0.6,0.4)p = (0.6, 0.4)p=(0.6,0.4)，则 δ2=(0.6,−0.6)\delta^2 = (0.6, -0.6)δ2=(0.6,−0.6)。W2W^2W2 的梯度是 δ2(a1)⊤\delta^2 (a^1)^{\top}δ2(a1)⊤，形状 2×32 \times 32×3；回传到隐藏层的信号是 (W2)⊤δ2(W^2)^{\top}\delta^2(W2)⊤δ2，再乘 ReLU 的掩码（z1>0z^1 > 0z1>0 处为 1，否则为 0）。

注意

  • 误差信号 δ\deltaδ 是"这个神经元的预激活变化一点，损失会变多少"。它同时承担两个职责：更新本层参数、把信号传给前一层。
  • ReLU 的掩码必须用前向保存的 zlz^lzl，不能用 ala^lal 重新判断（al=0a^l = 0al=0 既可能来自 z<0z < 0z<0，也可能来自 z=0z = 0z=0）。
  • batch 维度上，δ\deltaδ 是矩阵，参数梯度是对 batch 求平均或求和。求平均让梯度尺度与 batch 大小解耦。

上面的梯度公式可以用一次反向传播直接验证：交叉熵对 logits 的梯度就是 p−yp - yp−y。

import torch
import torch.nn.functional as F

torch.manual_seed(0)
x = torch.randn(3, 4)
y = torch.tensor([0, 2, 1])          # 类别下标，dtype 必须是 long

linear = torch.nn.Linear(4, 3)
logits = linear(x)                   # (3, 3)
loss = F.cross_entropy(logits, y)    # 标量
loss.backward()

with torch.no_grad():
    p = logits.softmax(dim=1)                       # (3, 3)
    onehot = F.one_hot(y, num_classes=3).float()
    manual = ((p - onehot).T @ x) / x.shape[0]      # (3, 4)
    print(torch.allclose(manual, linear.weight.grad, atol=1e-6))  # True

opt = torch.optim.AdamW(linear.parameters(), lr=1e-2)
opt.zero_grad()                      # 不清零，梯度会与上一次累加
loss = F.cross_entropy(linear(x), y)
loss.backward()
opt.step()

这段代码同时说明了两件事：手推的 p−yp - yp−y 与框架算出的梯度一致；一次完整的参数更新由 zero_grad → backward → step 三步组成，顺序错了就会累加梯度或更新到旧值。

把同样的网络写成 nn.Module，参数从哪来、怎么交给优化器，就一目了然了。

import torch
import torch.nn as nn

class TwoLayer(nn.Module):
    def __init__(self, d_in, d_hidden, d_out):
        super().__init__()
        self.fc1 = nn.Linear(d_in, d_hidden)
        self.fc2 = nn.Linear(d_hidden, d_out)

    def forward(self, x):
        return self.fc2(torch.relu(self.fc1(x)))

model = TwoLayer(4, 8, 3)
print(sum(p.numel() for p in model.parameters()))   # 4*8+8 + 8*3+3 = 67

for name, p in model.named_parameters():
    print(name, tuple(p.shape))   # fc1.weight (8, 4) / fc1.bias (8) ...

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

parameters() 只返回需要梯度的参数，named_parameters() 多给一个名字。优化器拿到的必须是同一批张量；重新赋值 model.fc1 = nn.Linear(...) 之后要重建优化器，否则它还在更新旧对象。

小结

反向传播的骨架只有三行：输出层 p−yp - yp−y，层间转置相乘再乘激活导数，参数梯度是误差信号乘输入。剩下的都是工程。

非线性、通用近似与深度

推导（没有非线性会怎样）

两层线性变换：W2(W1x)=(W2W1)xW^2(W^1 x) = (W^2 W^1)xW2(W1x)=(W2W1)x。乘积仍是一个线性变换，多层等价于一层。非线性是深度带来表达力的必要条件。

性质（通用近似）

单隐层网络在宽度足够大时，可以以任意精度逼近紧集上的连续函数。这个定理说明"表达力不是问题"，但它不说明：

  • 需要多宽；
  • 梯度下降能不能找到那组参数；
  • 找到的参数能不能泛化。

性质（深度相对于宽度的优势）

某些函数用深层网络表示只需要多项式级参数，用浅层网络需要指数级参数。直观上，深度允许复用中间组合：第 lll 层的特征可以被第 l+1l+1l+1 层的多个单元共享，宽度没有这种层级复用。

注意

  • 通用近似是存在性定理，不是学习保证。一个能表示所有函数的网络，可能因为优化困难或数据不足而学不到。
  • "更深更好"有边界。没有残差与归一化时，层数增加会让训练误差先降后升。

小结

非线性提供表达力，深度提供组合复用，通用近似保证"存在解"。三者合起来说明网络能表示复杂函数，但不保证能学到。

例：手算一次反向传播

例

取一个 2-2-1 网络，隐藏层为 ReLU，输出层为 sigmoid，损失为二元交叉熵。输入 x=(1,−1)x = (1, -1)x=(1,−1)，标签 y=1y = 1y=1。

前向：

z1=(12−11)(1−1)+(00)=(−1−2),a1=ReLU(z1)=(00)z^1 = \begin{pmatrix} 1 & 2 \\ -1 & 1 \end{pmatrix}\begin{pmatrix} 1 \\ -1 \end{pmatrix} + \begin{pmatrix} 0 \\ 0 \end{pmatrix} = \begin{pmatrix} -1 \\ -2 \end{pmatrix}, \qquad a^1 = \mathrm{ReLU}(z^1) = \begin{pmatrix} 0 \\ 0 \end{pmatrix} z1=(1−1​21​)(1−1​)+(00​)=(−1−2​),a1=ReLU(z1)=(00​)

小结

手算一遍能看清两件事：梯度是逐层相乘的，任何一层为零，后面全为零；初始化与激活函数的选择，直接决定第一次更新有没有信号。

边界：梯度消失、初始化与 batch size

性质（梯度消失）

sigmoid 的导数最大为 0.250.250.25，多层连乘后会指数衰减。LLL 层之后，梯度量级约为 0.25L0.25^L0.25L。tanh 稍好，但同样饱和。ReLU 在正半轴导数为 1，缓解了这个问题，代价是负半轴梯度为零。

性质（初始化）

初始化太小，信号逐层缩小；太大，逐层放大。Xavier 初始化让每层输出的方差与输入一致，He 初始化针对 ReLU 把方差放大两倍。两者都假设激活近似线性、输入独立。

性质（batch size）

  • batch 小：梯度噪声大，更新方向抖，但泛化有时更好；无法充分利用并行。
  • batch 大：梯度估计更准，吞吐高，但需要调大学习率，且可能落入尖锐极小值。
  • 显存占用随 batch 线性增长，这是大 batch 的硬约束。

注意

  • 梯度消失不是深层网络独有的。RNN 沿时间连乘、很深的卷积网络都会遇到。
  • 梯度裁剪只解决爆炸，不解决消失。消失要靠激活函数、初始化、归一化与残差。
  • batch size 与学习率通常要一起调。固定学习率、放大 batch，等效于降低更新次数。

小结

训练深网络的三个基本问题——信号消失、信号爆炸、梯度噪声——分别由激活函数、初始化与归一化、batch 与学习率来管。这是后面所有层的设计背景。

网络层与训练动力学

全连接层只提供线性变换与非线性。现代网络还堆了归一化、Dropout、残差与精心设计的初始化，它们不增加表达力，只让深层网络训得动、训得稳。

激活函数：饱和、死亡与选择

定义

  • sigmoid：σ(z)=1/(1+e−z)\sigma(z) = 1/(1+e^{-z})σ(z)=1/(1+e−z)，值域 (0,1)(0,1)(0,1)，导数 σ(z)(1−σ(z))≤0.25\sigma(z)(1-\sigma(z)) \le 0.25σ(z)(1−σ(z))≤0.25。
  • tanh：值域 (−1,1)(-1,1)(−1,1)，零中心，导数 1−tanh⁡2(z)≤11-\tanh^2(z) \le 11−tanh2(z)≤1。
  • ReLU：max⁡(0,z)\max(0, z)max(0,z)，正半轴导数 1，负半轴 0。
  • Leaky ReLU / PReLU：负半轴给一个小的斜率，避免完全死亡。
  • GELU / SiLU：平滑版 ReLU，在 Transformer 里常用。

性质

  • 饱和激活（sigmoid、tanh）在两端导数趋零，深层连乘会消失。
  • ReLU 不饱和，计算便宜，但负半轴梯度为零，学习率过大时单元会永久死亡。
  • 零中心很重要：tanh 的输出均值接近零，梯度更新更稳定；sigmoid 输出恒正，会让下一层梯度同号，收敛变慢。

注意

  • "ReLU 一定比 sigmoid 好"是过度结论。输出层用 sigmoid 是因为它要给概率，隐藏层用 ReLU 是因为它要不饱和，两者角色不同。
  • 死亡 ReLU 的判据是"对所有训练样本，预激活都小于零"。偶尔为零不是死亡。
  • 激活函数的选择要与初始化匹配：He 初始化假设 ReLU，Xavier 假设线性或 tanh。

小结

激活函数的选择标准只有两条：导数是否饱和、输出是否零中心。前者决定梯度能不能传下去，后者决定收敛快不快。

归一化：BN 的批统计与 LN 的样本统计

定义（批归一化）

对一个 mini-batch 内的每个特征维，减均值、除标准差，再仿射变换：

x^i=xi−μBσB2+ϵ,yi=γx^i+β\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \qquad y_i = \gamma \hat{x}_i + \beta x^i​=σB2​+ϵ​xi​−μB​​,yi​=γx^i​+β

μB,σB2\mu_B, \sigma_B^2μB​,σB2​ 是当前 batch 的统计量，γ,β\gamma, \betaγ,β 是可学习参数。

性质（训练与推理是两套行为）

  • 训练时用当前 batch 的均值方差，并对全局统计量做滑动平均。
  • 推理时用滑动平均的统计量，不再看当前 batch。

这是 BN 最容易搞错的地方：同一个模型，训练模式与推理模式的输出不同。忘记切换模式，或者 batch 太小导致统计量不稳，都会让推理结果漂移。

定义（层归一化）

对一个样本的所有特征维做归一化，不跨 batch：

x^=x−μσ2+ϵ,y=γx^+β\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y = \gamma \hat{x} + \beta x^=σ2+ϵ​x−μ​,y=γx^+β

性质（BN 与 LN 的分工）

  • BN 依赖 batch 维，适合固定长度的图像输入；batch 小或序列长度变化时统计量不稳。
  • LN 不依赖 batch，适合变长序列与自回归推理；Transformer 默认用 LN。
  • RMSNorm 去掉减均值，只做均方根归一化，计算更省，效果接近。

注意

  • BN 的原始动机"减少内部协变量偏移"后来受到质疑；它有效的部分原因可能是平滑了损失曲面，让更大的学习率可用。
  • BN 与 Dropout 同时使用时方差会偏移：训练时 Dropout 改变激活的方差，BN 又按 batch 统计量归一化，两者互相干扰。常见做法是二选一，或把 Dropout 放在 BN 之后并调小比例。
  • LN 在推理时不需要额外统计量，这是它在自回归模型里更受欢迎的原因之一。

小结

归一化解决的是"信号尺度随层数漂移"。BN 用 batch 统计量，LN 用样本统计量；前者适合图像，后者适合序列。

Dropout 与 inverted dropout

定义

训练时以概率 ppp 随机把每个神经元的输出置零，其余神经元按 1/(1−p)1/(1-p)1/(1−p) 缩放；推理时不做任何操作。

推导（为什么要缩放）

设某层输出为 hhh，训练时加掩码 m∼Bernoulli(1−p)m \sim \mathrm{Bernoulli}(1-p)m∼Bernoulli(1−p)，期望输出是 (1−p)h(1-p)h(1−p)h。为了让推理时的期望与训练时一致，训练时把保留的神经元乘以 1/(1−p)1/(1-p)1/(1−p)：

E[m1−ph]=h\mathbb{E}\left[\frac{m}{1-p}h\right] = h E[1−pm​h]=h

这就是 inverted dropout。早期实现是在推理时乘 (1−p)(1-p)(1−p)，现在框架默认是训练时缩放。

性质（它为什么有用）

  • 集成视角：每次训练相当于采样一个子网络，推理时近似对指数多个子网络取平均。
  • 抑制共适应：神经元不能依赖某个固定伙伴，必须学到独立有用的特征。

注意

  • Dropout 在卷积层上的效果通常弱于全连接层，因为卷积核共享参数，本身就有正则效果。
  • 数据规模上来之后，Dropout 的收益迅速下降；大模型预训练通常不用 Dropout。
  • 推理时忘记切模式，会把随机性带进线上。

训练与推理的两套行为可以直接观察：BN 的统计量在 train 时更新，Dropout 在 eval 时退化为恒等映射。

import torch

bn = torch.nn.BatchNorm1d(4)
drop = torch.nn.Dropout(p=0.5)
x = torch.randn(8, 4)                # (N, C) = (8, 4)

bn.train()
out_train = bn(x)                    # 用当前 batch 统计量，并更新 running stats
print(bn.running_mean.shape)         # (4,)

bn.eval()
out_eval = bn(x)                     # 用 running_mean / running_var
print(torch.allclose(out_train, out_eval))   # False：两套行为不同

drop.train()
print((drop(x) == 0).float().mean()) # 约 0.5 的元素被置零
drop.eval()
print(torch.equal(drop(x), x))       # True：推理时不做任何事

把这段代码与线上事故对照：忘了调用 eval()，BN 会用单个样本的统计量归一化，Dropout 会继续随机置零——训练时看不出来，推理时结果每次都不同。

小结

Dropout 用随机性换泛化。它的实现细节（缩放位置、与 BN 的顺序）比"加不加"更影响结果。

残差连接：让梯度绕过变换

定义

残差块把输入直接加到变换的输出上：

y=x+F(x)y = x + F(x) y=x+F(x)

推导（梯度流）

反向传播时：

∂y∂x=I+∂F∂x\frac{\partial y}{\partial x} = I + \frac{\partial F}{\partial x} ∂x∂y​=I+∂x∂F​

即使 ∂F/∂x\partial F/\partial x∂F/∂x 很小，梯度里仍有单位矩阵这一项，信号可以直接传到前面的层。没有残差时，梯度必须穿过整个 FFF，连乘后容易消失。

性质

  • 残差让网络学"增量"而不是"完整映射"。如果恒等映射已经够用，FFF 只需学零。
  • 残差与归一化的顺序影响训练稳定性。Post-LN（归一化在残差之后）在深层容易不稳；Pre-LN（归一化在子层之前）更稳，是现代 Transformer 的默认。

注意

  • 残差要求输入输出维度一致。维度不匹配时用 1×11 \times 11×1 卷积或线性投影对齐。
  • 残差不是"越深越好"的许可证。极深网络仍需要初始化与归一化配合，否则训练早期就会发散。

小结

残差把"深层连乘"变成"连乘加恒等"，给梯度一条短路。它是深层网络可训练的结构性原因，不是技巧。

初始化：让信号穿过很多层

定义（Xavier 初始化）

假设激活近似线性、输入零均值，令每层输出方差与输入一致：

Var(W)=2nin+nout\mathrm{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}} Var(W)=nin​+nout​2​

定义（He 初始化）

针对 ReLU 把负半轴截断、方差减半的事实，放大两倍：

Var(W)=2nin\mathrm{Var}(W) = \frac{2}{n_{\text{in}}} Var(W)=nin​2​

性质

初始化的目标是让前向的激活方差与反向的梯度方差在层间保持稳定。方差逐层缩小会导致信号消失，逐层放大会导致爆炸。

注意

  • 初始化必须打破对称性。全零初始化会让同一层的所有神经元收到相同梯度，永远学成同一个东西。
  • 偏置通常初始化为零，某些激活（如 ReLU）可以用小的正数，降低死亡概率。
  • 初始化与归一化有重叠：有 BN/LN 时，初始化的敏感度下降，但仍影响训练早期。

初始化的作用可以量出来：同一批数据，只改权重的标准差，看十层之后的激活尺度。

import torch
import torch.nn as nn

def activation_std(w_std, depth=10):
    net = nn.Sequential(*[m for _ in range(depth) for m in (nn.Linear(256, 256), nn.ReLU())])
    for layer in net:
        if isinstance(layer, nn.Linear):
            nn.init.normal_(layer.weight, std=w_std)
            nn.init.zeros_(layer.bias)
    x = torch.randn(512, 256)
    with torch.no_grad():
        return net(x).std().item()

print(activation_std(0.01))    # 约 1e-8：信号几乎消失
print(activation_std(0.088))   # 约 1：He 初始化，sqrt(2/256)
print(activation_std(0.2))     # 数百：信号被逐层放大

He 初始化的标准差是 2/nin\sqrt{2/n_{\text{in}}}2/nin​​，Xavier 是 2/(nin+nout)\sqrt{2/(n_{\text{in}}+n_{\text{out}})}2/(nin​+nout​)​。两者的差别来自 ReLU 把负半轴截断、方差减半这件事。

小结

初始化决定第一次前向与反向的信号尺度。它不改变模型的表达力，只改变优化能不能启动。

现代块的组合与顺序

性质（一个标准块）

以 Pre-LN Transformer 为例：

x←x+Attention(LN(x)),x←x+FFN(LN(x))x \leftarrow x + \mathrm{Attention}(\mathrm{LN}(x)), \qquad x \leftarrow x + \mathrm{FFN}(\mathrm{LN}(x)) x←x+Attention(LN(x)),x←x+FFN(LN(x))

两个子层各自包一层残差，归一化放在子层之前。

性质（顺序为什么重要）

  • Post-LN 把归一化放在残差之后，深层时残差分支的方差会累积，需要 warmup 才能训稳。
  • Pre-LN 让残差路径保持恒等，梯度可以直接回传，深层更稳；代价是表达力略弱，需要更多层补偿。

注意

  • 块内的顺序不是任意排列。把 FFN 放在注意力之前、把归一化放在残差之后，都会改变训练稳定性。
  • 现代 LLM 的结构是在这个块上做替换：LN 换 RMSNorm、ReLU 换 SwiGLU、绝对位置换 RoPE、多头换 GQA。替换的是部件，不是块的骨架。

Pre-LN 块的顺序在代码里只有一行：归一化、子层、残差相加。

import torch
import torch.nn as nn

class PreLNBlock(nn.Module):
    def __init__(self, d, hidden):
        super().__init__()
        self.ln = nn.LayerNorm(d)
        self.mlp = nn.Sequential(
            nn.Linear(d, hidden), nn.GELU(), nn.Linear(hidden, d)
        )

    def forward(self, x):
        return x + self.mlp(self.ln(x))   # 残差路径始终是恒等

x = torch.randn(2, 7, 32)                 # (N, L, d)
print(PreLNBlock(32, 128)(x).shape)       # (2, 7, 32)

把 return 改成 self.ln(x + self.mlp(x)) 就是 Post-LN。深层的稳定性差异就来自这个括号的位置：Pre-LN 让残差路径上没有归一化，梯度可以直通。

小结

现代网络的"层"已经不是单个运算，而是"归一化 + 子层 + 残差"的组合。理解这个组合，比记住某个模型的层数更有用。

卷积网络：局部性与参数共享

全连接层把输入当成一个扁平向量，丢掉了空间结构。卷积把"局部"与"平移"两个假设写进结构，用两个机制把参数量降下来。

全连接的代价：参数量爆炸

性质

一张 32×32×332 \times 32 \times 332×32×3 的彩色图展平是 3072 维。接一个 1000 维的全连接层，参数量是 3072×1000≈3.07×1063072 \times 1000 \approx 3.07 \times 10^63072×1000≈3.07×106。图像再大一点、网络再深一点，参数量按平方增长。

例

224×224×3224 \times 224 \times 3224×224×3 的输入展平是 150528 维，接 4096 维全连接层就是 6 亿参数，单层就超过了多数模型的预算。

注意

参数量不是唯一问题。全连接层对每个位置都用独立参数，等于假设"左上角的猫耳朵与右下角的猫耳朵是两种不同的模式"，这违背了图像的性质。

小结

全连接的代价有两层：参数量与"不共享统计强度"。卷积同时解决这两个问题。

稀疏连接与感受野

定义

卷积层的每个输出只连接输入的一个局部窗口（如 3×33 \times 33×3），这个窗口叫感受野。多个卷积层堆叠，感受野逐层扩大。

性质（感受野的增长）

k×kk \times kk×k 的卷积堆 LLL 层，感受野是 L(k−1)+1L(k-1) + 1L(k−1)+1。3×33 \times 33×3 堆两层得到 5×55 \times 55×5，堆三层得到 7×77 \times 77×7。用两个 3×33 \times 33×3 替代一个 5×55 \times 55×5，感受野相同，参数从 25 降到 18，还多了一次非线性。

注意

感受野是理论上界，实际有效感受野更小，且中心权重更大。堆得越深，边缘像素对输出的贡献越弱。

小结

稀疏连接把"每个输出看整张图"改成"每个输出看一小块"，参数量从 O(n2)O(n^2)O(n2) 降到 O(k2)O(k^2)O(k2)，同时保留了局部模式。

权值共享与卷积前向

定义

一个卷积核（filter）在整张图上滑动，所有位置共用同一组权重。输出是一张特征图（activation map）。

性质（平移等变）

输入平移一个像素，输出也平移一个像素——这叫平移等变。池化之后再平移，输出可能不变，这叫平移不变。CNN 的分类不变性来自"卷积等变 + 池化降采样"的组合，不是卷积单独提供的。

例（参数量）

输入 3 通道，用 10 个 5×55 \times 55×5 的卷积核：每个核的参数量是 3×5×5+1=763 \times 5 \times 5 + 1 = 763×5×5+1=76（含偏置），10 个核共 760。若用全连接层处理同样大小的输入，参数量是百万级。

注意

  • 卷积核的深度必须等于输入的通道数。多通道输入时，每个核在所有通道上都有权重，输出再按通道求和。
  • 多个卷积核产生多个输出通道，每个通道是一张特征图。输出通道数等于卷积核个数。

小结

权值共享把"每个位置一套参数"改成"全图一套参数"。它假设同一模式在不同位置含义相同，这个假设对图像成立，对某些结构化数据不成立。

空间维度：stride、padding 与输出尺寸

定义

  • stride：卷积核每次移动的步长。
  • padding：在输入边缘补零的圈数。
  • 输出尺寸：

O=⌊N+2P−FS⌋+1O = \left\lfloor \frac{N + 2P - F}{S} \right\rfloor + 1 O=⌊SN+2P−F​⌋+1

NNN 是输入边长，FFF 是核边长，PPP 是 padding，SSS 是 stride。

性质（same padding）

要让输出尺寸等于输入，取 P=(F−1)/2P = (F-1)/2P=(F−1)/2、S=1S = 1S=1。3×33 \times 33×3 核补 1 圈，5×55 \times 55×5 核补 2 圈。

注意

  • stride 大于 1 会降采样，输出尺寸变小；它替代了一部分池化的作用。
  • padding 引入的零会影响边缘统计，BN 在小特征图上对边缘尤其敏感。
  • 公式里的下取整意味着：输入尺寸不匹配时，最后一行/列会被丢弃。

卷积层的形状、参数量与乘加次数都能从超参数直接算出来，不需要打印整个模型。

import torch
import torch.nn as nn

conv = nn.Conv2d(in_channels=3, out_channels=10, kernel_size=5, stride=1, padding=2)
x = torch.randn(8, 3, 32, 32)        # (N, C, H, W)
y = conv(x)                          # (8, 10, 32, 32)
print(y.shape)

params = sum(p.numel() for p in conv.parameters())
print(params)                        # (3*5*5 + 1) * 10 = 760

macs = y.shape[0] * y.shape[2] * y.shape[3] * 10 * (3 * 5 * 5)
print(macs)                          # 8 * 32 * 32 * 10 * 75 = 6,144,000

pointwise = nn.Conv2d(64, 128, kernel_size=1)                       # 只混合通道
depthwise = nn.Conv2d(64, 64, kernel_size=3, padding=1, groups=64)  # 每通道单独卷积

参数量的公式是 (Cin⋅k2+1)⋅Cout(C_{\text{in}} \cdot k^2 + 1) \cdot C_{\text{out}}(Cin​⋅k2+1)⋅Cout​，乘加次数再乘上输出图的空间尺寸。1×11 \times 11×1 卷积与 depthwise 卷积改变的是这两个因子的结构，不是卷积的定义。

小结

stride 与 padding 是控制空间分辨率的两个旋钮。它们不改变卷积的假设，只改变信息流过的粒度。

池化、一维卷积与卷积变体

定义（池化）

池化在一个局部窗口里取最大值或平均值，输出一个数。它没有参数，作用是降采样与扩大感受野。

性质（池化的代价）

  • 最大池化保留最强响应，对微小位移不敏感，但丢掉位置信息。
  • 平均池化保留整体强度，对纹理更敏感。
  • 池化不可逆。分割、检测这类需要精确定位的任务，过度池化会损伤性能。

定义（一维卷积）

卷积核沿序列方向滑动，输入是 token 的向量序列。kkk 个 token 的窗口捕捉局部搭配，多个卷积核产生多个特征通道。文本上的卷积比图像更浅，通常叠加几层就够。

性质（常见变体）

  • 1×11 \times 11×1 卷积：不混合空间信息，只做通道间的线性组合，用于升降维。
  • depthwise 卷积：每个通道单独卷积，再配合 1×11 \times 11×1 做通道混合，参数与计算量大幅下降（MobileNet）。
  • dilated 卷积：卷积核带空洞，不增加参数就扩大感受野，适合长序列与高分辨率图像。

注意

池化不是必需的。现代网络常用 stride 卷积或 attention 替代池化，保留更多空间信息。

小结

池化用分辨率换不变性，1×11 \times 11×1 与 depthwise 用结构换效率，dilated 用空洞换感受野。三者都是对"局部性"假设的不同用法。

边界：归纳偏置什么时候不成立

性质（CNN 的两个假设）

  1. 局部性：相邻输入相关，远距离输入关系弱。
  2. 平移等变：同一模式在不同位置含义相同。

注意

  • 图像满足这两个假设，所以 CNN 高效。文本只部分满足：局部搭配成立，但长距离依赖（指代、篇章）不成立，所以文本上注意力更强。
  • 当数据量足够大时，Transformer 可以在图像上超过 CNN——它不是推翻了局部性，而是用数据把局部性学了回来。ViT 在小数据上不如 CNN，在大数据上反超，说明归纳偏置的价值随数据量下降。
  • 任务本身不满足平移等变时（如需要绝对位置、方向敏感），卷积的共享反而是负担。

小结

卷积不是"更好的全连接"，而是一组假设。假设成立时，它用更少参数换更好泛化；假设不成立时，它省下的参数变成了表达力的损失。

序列建模与注意力

图像的结构是空间的，序列的结构是时间的。循环网络把历史压进一个状态，注意力则让每个位置直接读取所有位置。这一章沿着"局部窗口、循环状态、全局交互"的顺序，说明每一步取消了什么假设、又付出了什么代价。

RNN 与 BPTT：状态、教师强制与梯度连乘

定义

循环神经网络在每个时间步用一个共享的更新函数：

ht=tanh⁡(Whht−1+Wxxt+b)h_t = \tanh\left(W_h h_{t-1} + W_x x_t + b\right) ht​=tanh(Wh​ht−1​+Wx​xt​+b)

输出由 hth_tht​ 经线性层与 softmax 给出。参数 Wh,Wx,bW_h, W_x, bWh​,Wx​,b 在所有时间步共享。

性质（语言模型视角）

把 xtx_txt​ 设为前一个 token 的嵌入，输出就是下一个 token 的分布。训练时用 teacher forcing：每个时间步的输入是真实的前一个 token，而不是模型自己的预测。

推导（BPTT 与梯度连乘）

损失对早期状态的梯度要穿过每一次状态转移：

∂ℓ∂ht=∑s≥t(∏k=t+1s∂hk∂hk−1)∂ℓ∂hs\frac{\partial \ell}{\partial h_t} = \sum_{s \ge t} \left(\prod_{k=t+1}^{s} \frac{\partial h_k}{\partial h_{k-1}}\right)\frac{\partial \ell}{\partial h_s} ∂ht​∂ℓ​=s≥t∑​(k=t+1∏s​∂hk−1​∂hk​​)∂hs​∂ℓ​

每一步的雅可比是 Wh⊤ diag(1−tanh⁡2(⋅))W_h^{\top}\,\mathrm{diag}\left(1 - \tanh^2(\cdot)\right)Wh⊤​diag(1−tanh2(⋅))。连乘的结果取决于 WhW_hWh​ 的谱半径与激活导数的乘积：小于 1 时指数衰减，大于 1 时指数爆炸。

注意

  • 梯度爆炸可以用裁剪（把范数压到阈值以内）处理；梯度消失没有同样廉价的解法，只能靠门控结构。
  • teacher forcing 让训练可以并行到时间步维度，但推理时必须逐步生成，训练与推理的输入分布不一致（暴露偏差）。
  • 隐藏状态是固定大小的向量，长序列的信息被压缩进同一个瓶颈。

小结

RNN 把"历史"压成一个状态，代价是梯度要沿时间连乘。状态大小固定，历史越长，丢得越多。

LSTM 与 GRU：门控在留住什么

定义（LSTM）

it=σ(Wi[ht−1;xt]+bi)ft=σ(Wf[ht−1;xt]+bf)ot=σ(Wo[ht−1;xt]+bo)c~t=tanh⁡(Wc[ht−1;xt]+bc)ct=ft⊙ct−1+it⊙c~tht=ot⊙tanh⁡(ct)\begin{aligned} i_t &= \sigma(W_i [h_{t-1}; x_t] + b_i) \\ f_t &= \sigma(W_f [h_{t-1}; x_t] + b_f) \\ o_t &= \sigma(W_o [h_{t-1}; x_t] + b_o) \\ \tilde{c}_t &= \tanh(W_c [h_{t-1}; x_t] + b_c) \\ c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t \\ h_t &= o_t \odot \tanh(c_t) \end{aligned} it​ft​ot​c~t​ct​ht​​=σ(Wi​[ht−1​;xt​]+bi​)=σ(Wf​[ht−1​;xt​]+bf​)=σ(Wo​[ht−1​;xt​]+bo​)=tanh(Wc​[ht−1​;xt​]+bc​)=ft​⊙ct−1​+it​⊙c~t​=ot​⊙tanh(ct​)​

性质（三个门的分工）

  • 遗忘门 ftf_tft​ 控制旧记忆保留多少；
  • 输入门 iti_tit​ 控制新信息写入多少；
  • 输出门 oto_tot​ 控制当前记忆暴露多少给外部。

细胞状态 ctc_tct​ 的更新是加法而不是连乘，梯度可以沿 ccc 的路径直接回传，这是 LSTM 缓解梯度消失的结构性原因。

定义（GRU）

GRU 合并了细胞状态与隐藏状态，只保留重置门 rtr_trt​ 与更新门 ztz_tzt​：

h~t=tanh⁡(W[rt⊙ht−1;xt]),ht=(1−zt)⊙ht−1+zt⊙h~t\tilde{h}_t = \tanh\left(W [r_t \odot h_{t-1}; x_t]\right), \qquad h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t h~t​=tanh(W[rt​⊙ht−1​;xt​]),ht​=(1−zt​)⊙ht−1​+zt​⊙h~t​

注意

  • 门控没有"解决"长依赖，只是把衰减速度放缓。序列足够长时，LSTM 仍会忘。
  • LSTM 与 GRU 的表现差异通常小于超参数与初始化带来的差异。选择依据是参数量、序列长度与训练成本。
  • 门控的值在 0 到 1 之间，饱和时梯度仍然小；层归一化与更好的初始化对深层 RNN 同样重要。

循环层的形状约定是固定的：输入 (N,L,din)(N, L, d_{\text{in}})(N,L,din​)，输出 (N,L,dout)(N, L, d_{\text{out}})(N,L,dout​)，状态按层数分组。

import torch
import torch.nn as nn

lstm = nn.LSTM(input_size=16, hidden_size=32, num_layers=2, batch_first=True)
x = torch.randn(4, 7, 16)            # (N, L, d_in)
out, (h_n, c_n) = lstm(x)

print(out.shape)                     # (4, 7, 32)：每个时间步的隐状态
print(h_n.shape)                     # (2, 4, 32)：每层的最终隐状态
print(c_n.shape)                     # (2, 4, 32)：每层的细胞状态

step_out, (h_n, c_n) = lstm(torch.randn(4, 1, 16), (h_n, c_n))
print(step_out.shape)                # (4, 1, 32)：逐 token 生成

逐 token 生成时只喂一个时间步，并把上一步的 (h,c)(h, c)(h,c) 传回去。这行代码就是"状态沿时间传递"的字面写法；注意力取消了它，也就取消了这份需要手动维护的状态。

变长序列必须打包，否则补齐的零会被当成真实输入，污染最后的状态。

import torch
import torch.nn as nn
from torch.nn.utils.rnn import pack_padded_sequence, pad_packed_sequence

lengths = torch.tensor([4, 3, 1])          # batch 内三条序列的真实长度
x = torch.randn(3, 4, 8)                   # (N, L, d)，短序列已补零

packed = pack_padded_sequence(x, lengths, batch_first=True, enforce_sorted=False)
lstm = nn.LSTM(8, 16, batch_first=True)
out_packed, (h, c) = lstm(packed)
out, out_lengths = pad_packed_sequence(out_packed, batch_first=True)

print(out.shape)        # (3, 4, 16)
print(h.shape)          # (1, 3, 16)：每个样本只累加自己的真实长度

不打包时，LSTM 会把补齐位置也算进状态，短句的最终状态被零稀释；enforce_sorted=False 让打包前不必先按长度排序。

小结

LSTM 用加法路径保护记忆，GRU 用两个门做同样的取舍。它们把"能记多久"从固定衰减变成可学习的参数。

seq2seq：编码器-解码器与它的瓶颈

定义

编码器把源序列压成一组状态，解码器根据这些状态逐 token 生成目标序列。最简形式只把编码器最后一个状态作为上下文：

c=hTenc,st=f(st−1,yt−1,c)c = h_T^{\text{enc}}, \qquad s_t = f(s_{t-1}, y_{t-1}, c) c=hTenc​,st​=f(st−1​,yt−1​,c)

性质（瓶颈）

所有源信息必须挤进一个固定长度的向量 ccc。源序列越长，压缩损失越大；解码器在生成每个词时，看到的上下文完全相同，无法"回头看"源句的不同部分。

注意

  • 这个瓶颈不是实现问题，是结构问题。加宽 ccc 只能推迟退化，不能消除。
  • 编码器与解码器可以不同（CNN 编码、RNN 解码），瓶颈与结构无关。
  • 翻译里的词对齐信息在纯 seq2seq 中是隐式的，注意力把它显式化。

小结

seq2seq 把"变长输入到变长输出"变成了可训练的问题，代价是固定长度的上下文向量。注意力就是为拆掉这个瓶颈而出现的。

注意力：QKV、缩放、多头与掩码

定义（注意力）

给定查询矩阵 Q∈Rn×dkQ \in \mathbb{R}^{n \times d_k}Q∈Rn×dk​、键矩阵 K∈Rm×dkK \in \mathbb{R}^{m \times d_k}K∈Rm×dk​、值矩阵 V∈Rm×dvV \in \mathbb{R}^{m \times d_v}V∈Rm×dv​：

Attention(Q,K,V)=softmax(QK⊤dk)V\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V Attention(Q,K,V)=softmax(dk​​QK⊤​)V

推导（为什么要除以 dk\sqrt{d_k}dk​​）

假设 QQQ 与 KKK 的每个分量独立、均值 0、方差 1，则内积 q⊤kq^{\top}kq⊤k 的方差是 dkd_kdk​。dkd_kdk​ 越大，内积的绝对值越大，softmax 越接近 one-hot，梯度越接近零（饱和）。除以 dk\sqrt{d_k}dk​​ 把方差拉回 1，让 softmax 落在梯度有效的区间。

性质（QKV 的分工）

  • QQQ 是"我在找什么"，KKK 是"我有什么标签"，VVV 是"我实际提供的内容"。
  • QK⊤QK^{\top}QK⊤ 给出相似度矩阵，softmax 按行归一化成权重，再对 VVV 加权求和。
  • 自注意力里 Q,K,VQ, K, VQ,K,V 都来自同一个输入序列，只是经过不同的线性投影。

定义（多头注意力）

把 ddd 维切成 hhh 份，每份独立做注意力，再拼接：

headi=Attention(QWiQ,KWiK,VWiV),MultiHead=Concat(head1,…,headh)WO\mathrm{head}_i = \mathrm{Attention}(QW_i^Q, KW_i^K, VW_i^V), \qquad \mathrm{MultiHead} = \mathrm{Concat}(\mathrm{head}_1, \dots, \mathrm{head}_h)W^O headi​=Attention(QWiQ​,KWiK​,VWiV​),MultiHead=Concat(head1​,…,headh​)WO

性质（多头的意义）

不同的头可以关注不同的关系：一个头看相邻词，一个头看句法依存，一个头看指代。总计算量与单头相近，因为每个头的维度是 d/hd/hd/h。

定义（掩码）

  • padding 掩码：把补齐位置的注意力权重设为 −∞-\infty−∞，softmax 后为 0。
  • 因果掩码：把未来位置的权重设为 −∞-\infty−∞，保证每个位置只能看左侧。

注意

  • 掩码必须在 softmax 之前加，且用很大的负数而不是零，否则 softmax 仍会分到概率。
  • 缩放因子是 dk\sqrt{d_k}dk​​，不是 d\sqrt{d}d​。多头里 dk=d/hd_k = d/hdk​=d/h。
  • 注意力的复杂度是 O(n2d)O(n^2 d)O(n2d)：序列长度平方增长。长文本的瓶颈在这里，不在参数量。

注意力的四步——打分、缩放、掩码、加权——可以直接写成矩阵运算。

import torch

def attention(q, k, v, mask=None):
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1) / d_k ** 0.5   # (N, Lq, Lk)
    if mask is not None:
        scores = scores.masked_fill(mask, float("-inf"))
    weights = scores.softmax(dim=-1)                 # 每行和为 1
    return weights @ v, weights

q = torch.randn(1, 4, 8)             # 一个句子、4 个 token、8 维
k = v = q

causal = torch.triu(torch.ones(4, 4), diagonal=1).bool()
out, w = attention(q, k, v, mask=causal)
print(w[0, 0])                       # [1, 0, 0, 0]：只能看到自己
print(w[0, 3])                       # 能看到全部四个位置

mha = torch.nn.MultiheadAttention(embed_dim=8, num_heads=2, batch_first=True)
out, _ = mha(q, k, v, attn_mask=causal)
print(out.shape)                     # (1, 4, 8)

掩码在 softmax 之前生效，被遮住的位置权重为零而不是"很小"；如果在 softmax 之后乘零，分母仍然包含它们，权重之和就不再是 1。

小结

注意力用"查询—键—值"把检索动作写成可微的矩阵运算。它取消了循环的固定状态，代价是序列长度的平方复杂度。

位置编码：顺序从哪里来

性质（注意力的排列不变性）

注意力对输入顺序是置换等变的：打乱 token 顺序，输出只是跟着打乱。没有位置信息，模型无法区分"猫追狗"与"狗追猫"。

定义（正弦位置编码）

PE(pos,2i)=sin⁡(pos100002i/d),PE(pos,2i+1)=cos⁡(pos100002i/d)PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right), \qquad PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right) PE(pos,2i)=sin(100002i/dpos​),PE(pos,2i+1)=cos(100002i/dpos​)

不同维度对应不同频率：低维变化快，高维变化慢。位置编码与词嵌入相加，进入网络。

定义（旋转位置编码 RoPE）

把 QQQ、KKK 的每一对维度按位置旋转一个角度：

(q2iq2i+1)↦(cos⁡θ−sin⁡θsin⁡θcos⁡θ)(q2iq2i+1),θ=pos⋅ωi\begin{pmatrix} q_{2i} \\ q_{2i+1} \end{pmatrix} \mapsto \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}\begin{pmatrix} q_{2i} \\ q_{2i+1} \end{pmatrix}, \qquad \theta = pos \cdot \omega_i (q2i​q2i+1​​)↦(cosθsinθ​−sinθcosθ​)(q2i​q2i+1​​),θ=pos⋅ωi​

性质（RoPE 的相对性）

两个位置的内积只依赖它们的相对距离：qm⊤knq_m^{\top}k_nqm⊤​kn​ 只与 n−mn - mn−m 有关。这让模型在训练长度之外仍有一定外推能力，也是现代 LLM 默认用 RoPE 的原因。

注意

  • 可学习位置嵌入在训练长度内更灵活，但无法外推到更长序列。
  • 绝对位置编码不携带"相对距离"的归纳偏置，模型需要从数据里学。
  • 位置编码的插值/外推是长上下文的核心难题之一，简单的线性插值会改变频率结构。

小结

注意力本身没有顺序概念，位置编码把顺序注入。绝对编码告诉模型"你在哪"，相对编码告诉模型"你离我多远"。

从 Transformer block 到现代 LLM 结构

定义（Transformer block）

一个编码器块由两个子层组成：

x←x+MultiHead(LN(x)),x←x+FFN(LN(x))x \leftarrow x + \mathrm{MultiHead}(\mathrm{LN}(x)), \qquad x \leftarrow x + \mathrm{FFN}(\mathrm{LN}(x)) x←x+MultiHead(LN(x)),x←x+FFN(LN(x))

FFN 是两层线性变换加激活，中间维度通常是 4d4d4d。解码器块多一个交叉注意力子层，并给自注意力加因果掩码。

性质（两个子层的分工）

  • 注意力负责 token 之间的信息交换（token mixing）；
  • FFN 负责 每个 token 内部的非线性变换（channel mixing）。

去掉 FFN，多层注意力会退化成低秩变换，表达力急剧下降；去掉注意力，FFN 只能逐位置处理，无法交换信息。

性质（现代 LLM 的部件替换）

部件原始现代动机代价
归一化LayerNormRMSNorm去掉均值，计算更省略弱的正则效果
激活ReLUSwiGLU门控，表达力更强参数量增加
位置绝对/正弦RoPE相对位置与外推频率设计敏感
注意力MHAGQA / MQA减少 KV cache表达力略降
FFN稠密MoE参数量与计算解耦路由与负载均衡复杂

注意

  • 这些替换都是"在同一个块骨架上换零件"，不是新架构。理解骨架比记住变体重要。
  • GQA 把多个查询头共享一组 KV 头，直接减少推理时的显存占用；它的收益在长上下文与高并发下最明显。
  • MoE 把 FFN 换成多个专家，每个 token 只激活少数几个。总参数量大，单次计算量小，但显存与通信成本高。

小结

Transformer 的结构可以概括为"注意力交换信息、FFN 变换特征、残差与归一化保证可训练"。现代 LLM 的差异主要在这四个位置上的替换。

规模、训练与工程约束

结构确定之后，模型的能力主要由三件事决定：投多少数据与算力、怎么训练、推理时受什么限制。这一章把它们分开讲，避免把"规模"当成一个笼统的原因。

缩放律：Kaplan 与 Chinchilla 的分歧

性质（Kaplan 的结论）

在固定算力下，损失随参数量、数据量、算力呈幂律下降：

L(N)∝N−0.076,L(D)∝D−0.095,L(C)∝C−0.050L(N) \propto N^{-0.076}, \qquad L(D) \propto D^{-0.095}, \qquad L(C) \propto C^{-0.050} L(N)∝N−0.076,L(D)∝D−0.095,L(C)∝C−0.050

Kaplan 的拟合建议把大部分新增算力投给参数，数据量的增长相对保守。

性质（Chinchilla 的修正）

Hoffmann 等人在更大的算力范围内重新拟合，发现最优参数量与数据量应当同比例增长：

Nopt∝C0.5,Dopt∝C0.5N_{\text{opt}} \propto C^{0.5}, \qquad D_{\text{opt}} \propto C^{0.5} Nopt​∝C0.5,Dopt​∝C0.5

经验比值约为每个参数 20 个 token。此前的模型普遍"参数过大、数据不足"。

注意

  • 两个结论的差异来自拟合范围与算力预算假设，不是"谁算错了"。在小算力区间，Kaplan 的建议仍然可用；在大算力区间，Chinchilla 的比例更省。
  • 缩放律是训练损失的规律，不是下游能力的规律。损失下降与具体任务提升之间没有一一对应。
  • 数据受限时（高质量 token 用完），继续增大参数不再划算，蒸馏、重复数据、合成数据的收益需要单独评估。

小结

缩放律回答"给定算力，参数与数据怎么配"。它给的是预算分配原则，不是能力保证。

预训练配方：数据、算力与目标

性质（数据）

  • 规模：token 数通常远大于参数量（Chinchilla 比例之后更是如此）。
  • 质量：去重、过滤低质页面、去除模板化内容。重复数据的边际收益迅速下降。
  • 配比：代码、数学、多语言、网页的比例影响能力结构；配比是超参数，需要消融。
  • 污染：训练数据混入评测集，会让所有下游指标虚高。

性质（目标与训练）

  • 自回归目标：每个位置预测下一个 token。
  • 批量与学习率：大 batch 配 warmup 与余弦衰减是常见组合。
  • 序列打包：把短文档拼成固定长度，减少 padding；要注意跨文档的注意力隔离。

注意

  • 预训练的目标函数很简单，难点在数据与稳定性。损失尖峰（loss spike）通常来自数据异常或学习率过大。
  • 数据配比没有普适最优。代码比例高会提升推理，但可能损害自然语言流畅度。
  • 训练成本主要在注意力与前向/反向的矩阵乘，通信开销在分布式训练里不可忽略。

混合精度省的是显存与带宽，代价是数值范围。一次前向就能看出 dtype 与误差量级。

import torch

x = torch.randn(1024, 1024, device="cuda")
w = torch.randn(1024, 1024, device="cuda")

with torch.autocast(device_type="cuda", dtype=torch.float16):
    y16 = x @ w                 # 矩阵乘在 fp16 下执行
y32 = x @ w                     # 走出 autocast，回到 fp32

print(y16.dtype)                # torch.float16
print((y16.float() - y32).abs().max())   # 误差量级，约 1e-2

fp16 的指数位少，梯度容易下溢，所以要用 GradScaler 放大 loss；bf16 的指数位与 fp32 相同，范围够大，通常不需要缩放。选哪一个取决于硬件支持，不是精度越高越好。

小结

预训练配方是"数据工程 + 稳定性工程"。目标函数只有一行，决定效果的是数据质量、配比与训练稳定性。

后训练：SFT、RLHF 与 DPO

定义（监督微调）

用指令—回答对做标准的交叉熵训练，让模型学会"按指令回答"的格式与风格。

定义（RLHF）

  1. 用人类偏好数据训练奖励模型；
  2. 用强化学习（通常是 PPO）最大化奖励，同时加 KL 惩罚，防止模型偏离预训练分布太远。

定义（DPO）

直接用偏好对优化策略，不需要显式奖励模型。它把"奖励差"写成策略对数概率差的函数，等价于带约束的偏好优化。

性质（三者的分工）

  • SFT 教格式与基本行为；
  • RLHF 优化"人类更喜欢哪个回答"，能处理难以用交叉熵表达的目标；
  • DPO 简化了 RLHF 的流程，训练更稳，但对偏好数据的质量同样敏感。

注意

  • 后训练改变的是行为偏好，不是知识。它不能让模型知道它没学过的事实。
  • 奖励模型会被"刷分"（reward hacking）：策略找到奖励模型的高分区域，但人类并不认可。
  • KL 惩罚是必要的：没有它，策略会退化成奖励模型的对抗样本。

后训练的监督微调仍然是交叉熵，只是要跳过 padding 位。

import torch
import torch.nn.functional as F

logits = torch.randn(2, 5, 100)      # (N, L, V)
targets = torch.tensor([[3, 7, 9, 2, 0],
                        [5, 1, 4, 2, 0]])
targets[:, -1] = -100                # padding 位不参与损失

# 实际训练时 targets 由 input_ids 右移一位得到，这里省略移位
loss = F.cross_entropy(logits.transpose(1, 2), targets, ignore_index=-100)
print(loss.item())

形状是 (N,V,L)(N, V, L)(N,V,L) 而不是 (N,L,V)(N, L, V)(N,L,V)：交叉熵要求类别维在中间。这个转置是 PyTorch 里最常见的形状错误之一，报错信息通常会指出维度不匹配。

小结

预训练给能力，后训练给行为。后训练的天花板由预训练决定，奖励模型的质量决定它能不能被正确引导。

推理的工程约束：KV cache、显存与量化

定义（KV cache）

自回归解码时，已生成 token 的 KKK、VVV 可以缓存，避免每步重算。缓存大小为

bytes=2×L×nkv×dhead×ntokens×b×batch\text{bytes} = 2 \times L \times n_{\text{kv}} \times d_{\text{head}} \times n_{\text{tokens}} \times b \times \text{batch} bytes=2×L×nkv​×dhead​×ntokens​×b×batch

其中 LLL 是层数，nkvn_{\text{kv}}nkv​ 是 KV 头数，bbb 是每个元素的字节数。

例

32 层、32 个 KV 头、每头 128 维、序列 8192、batch 1、fp16（2 字节）：2×32×32×128×8192×2≈4.32 \times 32 \times 32 \times 128 \times 8192 \times 2 \approx 4.32×32×32×128×8192×2≈4.3 GB，即 4.0 GiB。上下文翻倍，缓存翻倍。

性质（显存与带宽）

  • 解码是访存受限的：每生成一个 token，要把全部参数与 KV cache 读一遍，计算量很小。
  • 量化（int8、int4）减少显存占用与带宽压力，代价是精度损失；异常值（outlier）是量化的主要难点。
  • 并行策略：数据并行复制参数，张量并行切分单层，流水并行切分层；三种方式的通信模式不同。

注意

  • KV cache 是长上下文成本的主要来源。GQA/MQA 通过减少 nkvn_{\text{kv}}nkv​ 直接降低缓存。
  • 量化对困惑度的影响小，对长尾知识的影响可能很大；评测要覆盖事实性任务。
  • 批处理提高吞吐，但每个请求的缓存都要占显存，batch 与上下文长度互相挤占。

KV cache 的显存可以从超参数直接估算，GQA 的收益也在同一个式子里。

def kv_cache_gib(layers, n_kv_heads, head_dim, tokens, batch=1, bytes_per=2):
    total = 2 * layers * n_kv_heads * head_dim * tokens * batch * bytes_per
    return total / 1024 ** 3

print(kv_cache_gib(32, 32, 128, 8192))   # 4.0 GiB：32 个 KV 头
print(kv_cache_gib(32, 8, 128, 8192))    # 1.0 GiB：GQA，8 组 KV
print(kv_cache_gib(32, 8, 128, 32768))   # 4.0 GiB：上下文翻四倍

系数 2 来自 K 与 V 各一份。这个估算不含激活、临时缓冲区与碎片，实际占用会更高；但量级决定了长上下文能不能跑、并发能开多少。

小结

推理的瓶颈不是算力，是显存容量与带宽。KV cache、GQA、量化都是在这两个约束下做取舍。

测试时计算：从预训练到推理

性质（两个维度）

  • 并行：采样多个候选，用验证器或奖励模型选最好的。
  • 串行：生成更长的推理链，把计算花在中间步骤上。

注意

  • 验证器的质量决定并行采样的收益。验证器弱时，更多采样只是更多错误。
  • 串行推理的收益依赖任务：数学与代码受益明显，开放域写作未必。
  • 测试时计算与训练计算是两笔预算，不能直接相加比较；相同的成本下，增加训练还是增加推理，要看任务。

小结

规模不再只指训练。推理时的计算量成为第二个可扩展维度，但它需要验证器或可判定的任务来兑现。

涌现与评测：能力还是度量

性质（涌现的观察）

某些能力在小模型上接近随机，在超过某个规模后突然上升。Wei 等人的工作把这类现象称为涌现能力。

性质（度量的作用）

如果指标是非线性的（如精确匹配），平滑的能力提升会被显示成突变；换成线性或连续的指标，曲线可能变得平滑。所谓"涌现"，一部分是模型能力的跃迁，一部分是评测指标造成的错觉。

注意

  • 涌现的起点依赖任务、基线、指标与提示方式。换一种问法，"涌现"可能提前或消失。
  • 消融实验能区分"结构必需"与"规模补偿"：去掉 FFN 会导致表示秩坍缩，去掉残差会让深层无法训练，这些不是加参数能补的。
  • 缩放不保证能力。数据质量、目标函数、后训练都会改变曲线。

小结

规模是必要条件之一，不是充分条件。把"涌现"当成模型属性之前，先检查指标是否在制造突变。
