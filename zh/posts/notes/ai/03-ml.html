一、学习问题与泛化的边界

这一章不引入任何模型，只回答一个前置问题：机器学习凭什么可能？ 如果"在训练集上表现好"就等于"学会了"，那么查表就够了。真正的目标是在没见过的数据上也对，而这两件事之间没有逻辑上的必然联系。把这道缝补上，需要一条关于数据的假设，和一个把"大概"量化的工具。后面每一章（过拟合、正则化、模型选择）讨论的都是这道缝有多宽。

学习问题：五个组件与一个未知的目标

定义

监督学习由五个组件构成：

  • 目标函数 g:X→Yg: \mathcal{X} \to \mathcal{Y}g:X→Y：真实存在、我们想逼近的那个映射（例如银行真正的放贷标准）。它永远看不到。
  • 训练集 D={(x1,y1),…,(xn,yn)}D = \{(x_1, y_1), \dots, (x_n, y_n)\}D={(x1​,y1​),…,(xn​,yn​)}：从某个未知的联合分布 P(X,Y)P(X, Y)P(X,Y) 中抽样得到的观测。
  • 假设空间 H\mathcal{H}H：允许模型取值的函数集合（例如"所有线性函数"），它决定了学习的上限。
  • 模型 fθ∈Hf_\theta \in \mathcal{H}fθ​∈H：由参数 θ\thetaθ 指定的那一个具体函数。
  • 算法 AAA：从 DDD 中挑出 θ^\hat\thetaθ^ 的过程。

学习的产出是 f^θ\hat f_\thetaf^​θ​，评价标准是 f^θ≈g\hat f_\theta \approx gf^​θ​≈g。

性质（两个风险）

  • 期望风险：R(f)=E(X,Y)∼P[L(f(X),Y)]R(f) = \mathbb{E}_{(X,Y) \sim P}\left[L(f(X), Y)\right]R(f)=E(X,Y)∼P​[L(f(X),Y)]，模型在真实分布上的平均损失。这是我们真正想最小化的量。
  • 经验风险：R^n(f)=1n∑i=1nL(f(xi),yi)\hat R_n(f) = \frac{1}{n}\sum_{i=1}^{n} L(f(x_i), y_i)R^n​(f)=n1​∑i=1n​L(f(xi​),yi​)，模型在训练集上的平均损失。这是唯一能算出来的量。

因为 PPP 未知，期望风险无法直接计算。经验风险最小化（ERM）就是用 R^n\hat R_nR^n​ 代替 RRR 去最小化——它是一个不得已的替代，而本章其余部分就在讨论这个替代什么时候靠得住。

性质（任务形态）

按标签的类型划分：

  • 回归：YYY 连续，例如房价、销量。用 MSE、MAE 这类连续损失。
  • 分类：YYY 离散，涵盖二分类、多分类与多标签。输出层用 sigmoid（标签互相独立）或 softmax（类别互斥）把原始分数转成概率。
  • 结构化输出：标签不是标量，例如序列标注、机器翻译、目标检测。

注意

  • "有监督"描述的是训练范式，不是模型结构。同一个网络可以先在无标注数据上自监督预训练，再用标签做有监督微调，结构始终不变。
  • 标签质量决定性能上限。监督信号是唯一携带目标信息的来源，标注噪声无法靠更大的模型完全抵消。
  • ggg 未知是问题的根本困难。若 ggg 已知，学习退化为查表。
  • H\mathcal{H}H 决定能学到什么。线性假设空间里永远学不出异或——换算法解决不了，这是表达能力的问题。

小结

学习是用一个受限的函数集合去逼近一个未知映射，手里只有有限个样本，能算的只有经验风险。

训练表现不等于测试表现

例（训练与测试可以完全无关）

下面两组数据只差一个符号：

集合jobsalaryapprove?
训练310−1-1−1
训练00+1+1+1
测试310+1+1+1
测试00−1-1−1

模型"job 与 salary 都为 000 就通过"在训练集上 100% 正确，在测试集上 100% 错误。

注意

  • 这不是构造出来的玩具。它说明的是：如果对训练样本与测试样本之间的关系不作任何假设，训练表现携带的关于测试表现的信息可以是零。
  • 把已经见过的数据预测正确，不叫学习，叫记忆。
  • 出路只有一条：必须对"训练数据与测试数据有什么关系"作出假设。

小结

没有假设就没有泛化。这是后面所有泛化保证的起点。

学习可行的两条前提：i.i.d. 与概率式保证

定义

  • 独立同分布（i.i.d.）假设：训练样本与测试样本都独立地取自同一个未知分布 P(X,Y)P(X, Y)P(X,Y)。
  • 概率式保证：不断言"一定正确"，而是断言"以很高的概率足够接近正确"。

性质（为什么必须放弃确定性）

  • 不作假设、又要求确定性地预测测试样本——学习不可行，上一节的反例就是证据。
  • 接受 i.i.d. 之后，可以只要求概率上成立：样本足够多时，"样本里的规律"以高概率接近"总体里的规律"。

这就是课件里说的 possible versus probable：绝对的可能没有，高概率的可能有。

注意

  • i.i.d. 是关于数据来源的假设，不是关于世界的定理。它经常被破坏：时间序列（今天与昨天相关）、分布漂移（线下训练、线上服务）、采样偏差（只采到某个群体）。这些情况下泛化保证已经失效，而模型不会报错——这是生产事故里最常见的一类根因。
  • "概率式"不是退让，而是唯一可计算的形式：它把"能不能学会"换成了"需要多少样本、能学到多准"。

小结

学习可行的前提是两条：数据 i.i.d.，且只要求概率意义上的正确。

Hoeffding 不等式：把"大概"量化

定义（抽球模型）

一个罐子里装红球和绿球，红球比例 μ\muμ 未知。有放回地独立抽取 nnn 个球，其中红球比例为 ν\nuν。

问题：ν\nuν 能说明 μ\muμ 的什么？

对任意 ε>0\varepsilon > 0ε>0，

Pr⁡[ ∣ν−μ∣>ε ]≤2e−2nε2\Pr\left[\,|\nu - \mu| > \varepsilon\,\right] \le 2e^{-2n\varepsilon^2} Pr[∣ν−μ∣>ε]≤2e−2nε2

推导（三个量知二求一）

不等式里有 nnn、ε\varepsilonε、δ\deltaδ 三个可调的量：

  • 固定 nnn 与 ε\varepsilonε：得到"偏离超过 ε\varepsilonε"的概率上界。
  • 固定精度 ε\varepsilonε 与失败概率 δ\deltaδ：反解出所需样本量

n≥12ε2ln⁡2δn \ge \frac{1}{2\varepsilon^2}\ln\frac{2}{\delta} n≥2ε21​lnδ2​

即"以至少 1−δ1-\delta1−δ 的概率保证 ∣ν−μ∣≤ε|\nu - \mu| \le \varepsilon∣ν−μ∣≤ε"。

取 ε=0.1\varepsilon = 0.1ε=0.1、δ=0.05\delta = 0.05δ=0.05：

注意

  • ε\varepsilonε 是精度（允许多大偏差），δ\deltaδ 是置信度（允许多小失败概率），nnn 是代价。三者的换算关系是明确的，这就是"量化"的含义。
  • 精度是平方级的代价：ε\varepsilonε 减半，nnn 要变成四倍。这与概率章里标准误 σ/n\sigma/\sqrt{n}σ/n​ 是同一件事的两面。
  • 置信度是廉价的：δ\deltaδ 只进对数，把失败概率从 0.050.050.05 压到 0.0010.0010.001 只需要多一点样本。

小结

Hoeffding 把"样本能说明总体"从直觉变成了可计算的换算关系：精度、置信度、样本量三者知二求一。

PAC：把学习目标改写成概率形式

定义

一个模型是 PAC 可学的，如果对任意 ε>0\varepsilon > 0ε>0、δ>0\delta > 0δ>0，都存在样本量 n(ε,δ)n(\varepsilon, \delta)n(ε,δ)，使得用 nnn 个样本学出的模型 hhh 以至少 1−δ1-\delta1−δ 的概率满足

∣Eout(h)−Ein(h)∣≤ε\left|E_{\text{out}}(h) - E_{\text{in}}(h)\right| \le \varepsilon ∣Eout​(h)−Ein​(h)∣≤ε

其中 Ein(h)E_{\text{in}}(h)Ein​(h) 是 hhh 在训练集上的误差，Eout(h)E_{\text{out}}(h)Eout​(h) 是 hhh 在整个分布上的期望误差。

性质（抽球模型到学习模型的对应）

这是整个可行性论证的核心类比：

抽球学习

于是 Hoeffding 直接给出：对某一个固定的假设 hhh，Ein(h)E_{\text{in}}(h)Ein​(h) 与 Eout(h)E_{\text{out}}(h)Eout​(h) 的差距大概率很小。

注意（这个类比缺了一步）

抽球模型里只有一个对象 μ\muμ，而学习要在很多个假设中挑一个。"挑"这个动作本身破坏了前提：被选中的假设恰恰因为在 DDD 上表现好才被选中，它天然偏向 DDD。

补上这一步需要联合界与 VC 维，下一节给结论。

小结

PAC 把学习目标从"一定正确"改写成"以高概率近似正确"——在 i.i.d. 前提下，这是唯一能达到的目标形态。

从抽球到假设空间：VC 维与泛化界

定义

VC 维 dVC(H)d_{VC}(\mathcal{H})dVC​(H)：假设空间 H\mathcal{H}H 能打散的最大点集大小。所谓打散 mmm 个点，指这 mmm 个点上的全部 2m2^m2m 种标记方式都能被 H\mathcal{H}H 中的某个函数实现。

性质（泛化界）

以至少 1−δ1-\delta1−δ 的概率，同时对所有 h∈Hh \in \mathcal{H}h∈H 成立

Eout(h)≤Ein(h)+8nln⁡4 mH(2n)δE_{\text{out}}(h) \le E_{\text{in}}(h) + \sqrt{\frac{8}{n}\ln\frac{4\,m_{\mathcal{H}}(2n)}{\delta}} Eout​(h)≤Ein​(h)+n8​lnδ4mH​(2n)​​

其中 mH(⋅)m_{\mathcal{H}}(\cdot)mH​(⋅) 是增长函数，即 H\mathcal{H}H 在给定点集上能实现的不同标记数。dVCd_{VC}dVC​ 有限时有 mH(N)≤NdVC+1m_{\mathcal{H}}(N) \le N^{d_{VC}+1}mH​(N)≤NdVC​+1，代入后得到更实用的形式

Eout(h)≤Ein(h)+8n(ln⁡4δ+(dVC+1)ln⁡(2n))E_{\text{out}}(h) \le E_{\text{in}}(h) + \sqrt{\frac{8}{n}\left(\ln\frac{4}{\delta} + (d_{VC}+1)\ln(2n)\right)} Eout​(h)≤Ein​(h)+n8​(lnδ4​+(dVC​+1)ln(2n))​

性质（怎么读这个界）

  • nnn 越大界越紧，量级是 1/n1/\sqrt{n}1/n​——数据多总是有用。
  • dVCd_{VC}dVC​ 越大界越松——假设空间越大，越容易在 DDD 上"碰巧"挑到一个好假设，泛化代价越高。
  • 它把"模型太强会出问题"从定性说法变成了定量结论：模型复杂度以 dVCln⁡n/n\sqrt{d_{VC}\ln n / n}dVC​lnn/n​ 的代价进入泛化误差。

性质（几个常见假设空间的 VC 维）

  • Rd\mathbb{R}^dRd 上的线性分类器：dVC=d+1d_{VC} = d + 1dVC​=d+1。
  • 一维区间分类器：dVC=2d_{VC} = 2dVC​=2。
  • 最近邻（1-NN）：dVC=∞d_{VC} = \inftydVC​=∞。

注意

  • VC 维衡量表达能力，不是参数个数。参数量相近的两个网络，结构不同，VC 维可以差很多。
  • 最近邻那一行是重要的反例：dVC=∞d_{VC} = \inftydVC​=∞ 意味着这个界给不出任何有用信息，但 kkk-NN 在实践中表现良好。界是充分条件，不是必要条件——界松不代表泛化差。
  • 同样的道理适用于深度网络：它的 VC 维极大，按这个界推出来的样本量会大到荒谬，但实际训练依然能泛化。这说明 VC 界没有完整解释"深度学习为什么能工作"，那部分需要别的机制（隐式正则、平坦极小值等），目前仍是没有完全解决的问题。
  • 这个界的价值在于给方向（数据量和复杂度往哪边调），不在于代入数值。

小结

泛化界把一个承诺变成了一个可检查的不等式：训练误差加上一个复杂度项。

经验风险最小化与结构风险最小化

定义

  • 经验风险最小化（ERM）：直接在 H\mathcal{H}H 里最小化训练误差

f^ERM=arg⁡min⁡f∈HR^n(f)\hat f_{\text{ERM}} = \arg\min_{f \in \mathcal{H}} \hat R_n(f) f^​ERM​=argf∈Hmin​R^n​(f)

  • 结构风险最小化（SRM）：最小化"训练误差 + 复杂度惩罚"

f^SRM=arg⁡min⁡f∈H[R^n(f)+Ω(H)]\hat f_{\text{SRM}} = \arg\min_{f \in \mathcal{H}} \left[\hat R_n(f) + \Omega(\mathcal{H})\right] f^​SRM​=argf∈Hmin​[R^n​(f)+Ω(H)]

其中 Ω\OmegaΩ 可以是 VC 维、参数范数，或任何能刻画复杂度的量。

推导（SRM 是从哪来的）

上一个不等式给出

Eout≤Ein+Ω(H,n,δ)E_{\text{out}} \le E_{\text{in}} + \Omega(\mathcal{H}, n, \delta) Eout​≤Ein​+Ω(H,n,δ)

右边这个上界完全由可计算的量组成（EinE_{\text{in}}Ein​、nnn、δ\deltaδ、H\mathcal{H}H 的复杂度）。与其最小化左边的未知量，不如直接最小化右边的已知上界——这正是 SRM 在做的事。

注意

  • ERM 的失败模式是"把复杂度选得太大"：H\mathcal{H}H 足够大时总能把 R^n\hat R_nR^n​ 压到 000，而此时复杂度项已经把界撑开到毫无意义。这就是过拟合的定量图像。
  • SRM 的难点在 Ω\OmegaΩ 的选取：VC 维只是一个选项，而且对深度网络往往过于悲观。实践中用参数范数、权重衰减、Dropout 等作为复杂度的代理，它们和 SRM 是同一个思想的不同实现。
  • ERM 不是"错的"：它有泛化保证（一致性），只是那个保证要求假设空间随样本量一起增长得足够慢。样本量固定时，纯粹 ERM 不足以控制泛化。

小结

ERM 只优化看得见的训练误差，SRM 连看不见的那一项一起优化。泛化问题到这里被转化成了一个优化问题：在"拟合得更好"和"更简单"之间取舍。 下一章的线性模型会用同样的框架落到具体算法上，第四章则专门讲怎么做这个取舍。

二、线性模型：感知机、线性回归与逻辑回归

线性模型是机器学习的"最小可用单元"：它足够简单，可以手算出全部解；又足够有用，到今天仍然是工业界的主力。更重要的是，后面所有复杂模型（神经网络、Transformer）都是在这个骨架上加东西长出来的——先看清楚骨架，才知道后来加的是什么。

这一章讲三个模型：感知机、线性回归、逻辑回归。它们的假设空间完全相同，差别只在输出层和损失。

线性模型：一个假设空间家族

定义

线性模型取

fθ(x)=θ⊤x+bf_\theta(x) = \theta^{\top}x + b fθ​(x)=θ⊤x+b

其中 θ∈Rd\theta \in \mathbb{R}^dθ∈Rd 是权重、b∈Rb \in \mathbb{R}b∈R 是偏置。给 xxx 前面补一个恒为 111 的分量、同时把 bbb 并入 θ\thetaθ，就得到更紧凑的形式

fθ(x)=θ⊤x,x=(1,x1,…,xd)⊤f_\theta(x) = \theta^{\top}x, \qquad x = (1, x_1, \dots, x_d)^{\top} fθ​(x)=θ⊤x,x=(1,x1​,…,xd​)⊤

这一步叫偏置吸收：它不改变模型，只让公式少一项，后面统一用它。

模型输出损失输出空间
感知机sign⁡(θ⊤x)\operatorname{sign}(\theta^{\top}x)sign(θ⊤x)误分类驱动（无显式损失）{−1,+1}\{-1, +1\}{−1,+1}

逻辑回归σ(θ⊤x)\sigma(\theta^{\top}x)σ(θ⊤x)交叉熵(0,1)(0,1)(0,1)，解释为概率

三者共用同一个 θ⊤x\theta^{\top}xθ⊤x：先把输入线性组合成一个得分，再决定怎么用它。

注意

  • 线性模型的表达能力有明确上限：学不出异或，也学不出任何需要特征交互的模式。突破它的方式只有两种——换特征（人工构造，或用核方法隐式地换）与堆叠非线性（神经网络）。
  • "线性"指的是对参数线性，不是对输入线性。把 xxx 换成 ϕ(x)\phi(x)ϕ(x)（比如多项式特征）之后 θ⊤ϕ(x)\theta^{\top}\phi(x)θ⊤ϕ(x) 仍然是线性模型，但它关于原始输入的决策边界可以是曲线。

小结

线性模型 = 线性得分 + 输出变换。三个基础模型的差别全在后一步，不在假设空间。

感知机：只要分对，不要概率

定义

线性分类要找的是一个线性函数，把训练集分开：

fθ(xi)>0 若 yi=+1,fθ(xi)<0 若 yi=−1f_\theta(x_i) > 0 \text{ 若 } y_i = +1, \qquad f_\theta(x_i) < 0 \text{ 若 } y_i = -1 fθ​(xi​)>0 若 yi​=+1,fθ​(xi​)<0 若 yi​=−1

取 yi∈{−1,+1}y_i \in \{-1, +1\}yi​∈{−1,+1}，这两条可以紧凑地写成 yi=sign⁡(fθ(xi))y_i = \operatorname{sign}(f_\theta(x_i))yi​=sign(fθ​(xi​))。

算法（感知机）

  1. 任取初始 θ\thetaθ；
  2. 挑一个被误分类的样本 xix_ixi​，即 sign⁡(θ⊤xi)≠yi\operatorname{sign}(\theta^{\top}x_i) \ne y_isign(θ⊤xi​)=yi​；
  3. 更新 θ←θ+yixi\theta \leftarrow \theta + y_i x_iθ←θ+yi​xi​；
  4. 重复，直到没有误分类样本。

推导（更新规则为什么长这样）

看更新之后模型对刚被挑中的那个样本的输出：

θnew⊤xi=(θ+yixi)⊤xi=θ⊤xi+yi∥xi∥22\theta_{\text{new}}^{\top}x_i = (\theta + y_ix_i)^{\top}x_i = \theta^{\top}x_i + y_i\|x_i\|_2^2 θnew⊤​xi​=(θ+yi​xi​)⊤xi​=θ⊤xi​+yi​∥xi​∥22​

两边乘 yiy_iyi​（注意 yi2=1y_i^2 = 1yi2​=1）：

yiθnew⊤xi=yiθ⊤xi+∥xi∥22y_i\theta_{\text{new}}^{\top}x_i = y_i\theta^{\top}x_i + \|x_i\|_2^2 yi​θnew⊤​xi​=yi​θ⊤xi​+∥xi​∥22​

被误分类意味着 yiθ⊤xi<0y_i\theta^{\top}x_i < 0yi​θ⊤xi​<0。所以更新之后这个量恰好加了一个正数——朝着"让它被正确分类"的方向挪了一步。

几何上就是：yi=+1y_i = +1yi​=+1 时把 θ\thetaθ 往 xix_ixi​ 的方向转，yi=−1y_i = -1yi​=−1 时往 −xi-x_i−xi​ 的方向转。

性质（收敛性）

  • 数据线性可分时，感知机在有限步内收敛（Novikoff 定理）。
  • 线性不可分时不收敛，会一直震荡。
  • 收敛时停下的那个超平面不唯一：取决于初始值和每次挑哪个误分类样本。

注意

  • 感知机只回答"分对没有"，不给置信度。θ⊤x\theta^{\top}xθ⊤x 的大小没有概率含义，所以它没法用于排序、阈值调优、代价敏感决策这类场合。
  • 不唯一在生产上很麻烦：同一个训练集跑两次可能得到不同的分割面，行为不可复现。这个缺陷正是 SVM 要解决的——在无穷多个可分的超平面里，挑一个判据明确的。
  • yi∈{0,1}y_i \in \{0, 1\}yi​∈{0,1} 时更新要写成 θ←θ+(yi−y^i)xi\theta \leftarrow \theta + (y_i - \hat y_i)x_iθ←θ+(yi​−y^​i​)xi​，本质相同。

小结

感知机是线性分类的最小实现：分对就停，不问置信度。它的两个短板——不唯一、无概率——分别由 SVM 和逻辑回归接手。

线性回归：最小二乘与闭式解

定义

线性回归假设输出是输入的线性函数 yi≈θ⊤xiy_i \approx \theta^{\top}x_iyi​≈θ⊤xi​。把 nnn 个样本按行堆成 X∈Rn×dX \in \mathbb{R}^{n \times d}X∈Rn×d、标签堆成 y∈Rny \in \mathbb{R}^ny∈Rn，最小二乘的目标是

θ^=arg⁡min⁡θ  1n∥Xθ−y∥22\hat\theta = \arg\min_\theta \; \frac{1}{n}\|X\theta - y\|_2^2 θ^=argθmin​n1​∥Xθ−y∥22​

性质（结论，完整推导在数学讲义的线性代数部分）

  • 求梯度并令其为零，得到法方程 X⊤Xθ^=X⊤yX^{\top}X\hat\theta = X^{\top}yX⊤Xθ^=X⊤y。
  • XXX 列满秩时 X⊤XX^{\top}XX⊤X 正定、可逆，闭式解为

θ^=(X⊤X)−1X⊤y=X†y\hat\theta = (X^{\top}X)^{-1}X^{\top}y = X^{\dagger}y θ^=(X⊤X)−1X⊤y=X†y

  • 秩亏时解不唯一，此时取最小范数解 X†yX^{\dagger}yX†y（伪逆由 SVD 定义，对秩亏天然免疫）。
  • 几何上，Xθ^X\hat\thetaXθ^ 是 yyy 在列空间 Col⁡(X)\operatorname{Col}(X)Col(X) 上的正交投影，残差 y−Xθ^y - X\hat\thetay−Xθ^ 与整个列空间正交。
  • 若噪声是独立高斯分布，最小二乘等价于极大似然估计——这是它被广泛使用的统计学理由。

注意

  • 闭式解在数值上不要真的求逆。显式构造 (X⊤X)−1(X^{\top}X)^{-1}(X⊤X)−1 会把条件数平方（κ(X⊤X)=κ(X)2\kappa(X^{\top}X) = \kappa(X)^2κ(X⊤X)=κ(X)2），误差被放大。实践用 QR 或 SVD，对应 numpy.linalg.lstsq / pinv。
  • 线性回归的边界是"输出与输入线性相关"，不是"数据看起来是直的"。通常要先做特征变换（多项式、对数、交互项）再回归，而这正是"线性模型 + 特征工程"能覆盖大量场景的原因。
  • 最小二乘对离群点敏感，因为误差被平方。需要抗离群点时换成绝对误差（MAE），代价是目标函数在零点不可导。

小结

线性回归把拟合变成了一个能直接求解的二次优化：列满秩时法方程给出唯一解，几何上是投影，统计上是高斯噪声下的极大似然。

逻辑回归：把线性得分压成概率

定义

逻辑回归把线性得分送进 sigmoid：

p^=σ(θ⊤x)=11+e−θ⊤x\hat p = \sigma(\theta^{\top}x) = \frac{1}{1 + e^{-\theta^{\top}x}} p^​=σ(θ⊤x)=1+e−θ⊤x1​

p^\hat pp^​ 解释为 P(y=1∣x)P(y = 1 \mid x)P(y=1∣x)。预测时取 y^=1[p^>0.5]\hat y = \mathbf{1}[\hat p > 0.5]y^​=1[p^​>0.5]，也就是 sign⁡(θ⊤x)\operatorname{sign}(\theta^{\top}x)sign(θ⊤x)——决策边界仍然是线性的。

sigmoid 本身的三条性质够用：值域是 (0,1)(0,1)(0,1)，σ(0)=0.5\sigma(0) = 0.5σ(0)=0.5，导数 σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)\left(1 - \sigma(z)\right)σ′(z)=σ(z)(1−σ(z))。

性质（为什么是 sigmoid 而不是别的）

由定义反解：

log⁡p^1−p^=θ⊤x\log\frac{\hat p}{1 - \hat p} = \theta^{\top}x log1−p^​p^​​=θ⊤x

左边是对数几率（log-odds）。所以逻辑回归的假设是"对数几率是输入的线性函数"。

这比"概率是输入的线性函数"合理得多：后者会算出小于 000 或大于 111 的"概率"。sigmoid 不是随便挑的一个 S 形函数，它是对数几率线性的逆变换。

注意

  • 逻辑回归是分类器，不是回归器——名字里的"回归"来自它建模的对象是对数几率。
  • 决策边界线性，但概率不是线性的。离边界越远（∣θ⊤x∣|\theta^{\top}x|∣θ⊤x∣ 越大），概率越贴近 000 或 111；边界附近概率接近 0.50.50.5。
  • p^\hat pp^​ 的绝对大小不一定可信。线性可分的数据上参数会趋向无穷（下一节解释原因），此时所有概率都被推到极端。

小结

逻辑回归 = 线性得分 + 一个把实数压到 (0,1)(0,1)(0,1) 的单调变换，输出同时给出类别判定和置信程度。

逻辑回归的损失：从伯努利似然到交叉熵

推导（极大似然直接给出交叉熵）

单个样本的标签服从伯努利分布，写成 P(y∣x)=p^ y(1−p^)1−yP(y \mid x) = \hat p^{\,y}(1-\hat p)^{1-y}P(y∣x)=p^​y(1−p^​)1−y，其中 p^=σ(θ⊤x)\hat p = \sigma(\theta^{\top}x)p^​=σ(θ⊤x)。

nnn 个样本独立时，似然是各项相乘：

L(θ)=∏i=1np^i yi(1−p^i)1−yiL(\theta) = \prod_{i=1}^{n}\hat p_i^{\,y_i}\left(1 - \hat p_i\right)^{1-y_i} L(θ)=i=1∏n​p^​iyi​​(1−p^​i​)1−yi​

取对数把乘积变成求和：

log⁡L(θ)=∑i=1n[ yilog⁡p^i+(1−yi)log⁡(1−p^i) ]\log L(\theta) = \sum_{i=1}^{n}\left[\,y_i\log\hat p_i + (1-y_i)\log(1-\hat p_i)\,\right] logL(θ)=i=1∑n​[yi​logp^​i​+(1−yi​)log(1−p^​i​)]

最大化它，等价于最小化二元交叉熵损失

ℓ(θ)=−∑i=1n[ yilog⁡p^i+(1−yi)log⁡(1−p^i) ]\ell(\theta) = -\sum_{i=1}^{n}\left[\,y_i\log\hat p_i + (1-y_i)\log(1-\hat p_i)\,\right] ℓ(θ)=−i=1∑n​[yi​logp^​i​+(1−yi​)log(1−p^​i​)]

推导（梯度意外地干净）

用 σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)(1-\sigma(z))σ′(z)=σ(z)(1−σ(z)) 逐步求导，单个样本的梯度是

∂ℓi∂θ=(p^i−yi)xi\frac{\partial \ell_i}{\partial\theta} = \left(\hat p_i - y_i\right)x_i ∂θ∂ℓi​​=(p^​i​−yi​)xi​

也就是说：逻辑回归的梯度形式与线性回归完全一致——"预测值减真实值，再乘输入"。 区别只在 p^i\hat p_ip^​i​ 经过了 sigmoid。

性质（凸性）

ℓ(θ)\ell(\theta)ℓ(θ) 是凸函数：它的 Hessian 是

∇2ℓ(θ)=X⊤diag⁡ ⁣(p^i(1−p^i))X\nabla^2\ell(\theta) = X^{\top}\operatorname{diag}\!\left(\hat p_i(1-\hat p_i)\right)X ∇2ℓ(θ)=X⊤diag(p^​i​(1−p^​i​))X

每个 p^i(1−p^i)>0\hat p_i(1-\hat p_i) > 0p^​i​(1−p^​i​)>0，所以 Hessian 半正定。因此极小点唯一，梯度下降一定能收敛到全局最优——这是逻辑回归到今天仍在用的主要原因。

注意

  • 数据线性可分时，逻辑回归的参数会发散。似然要更大，只能让 ∥θ∥→∞\|\theta\| \to \infty∥θ∥→∞，把每个样本的概率都推向 000 或 111；损失永远不为零，参数永远不停。这被称为完全分离问题，实践中靠加正则项解决——正则化在这里不是"防过拟合的可选项"，而是让解存在的必要条件。
  • 交叉熵不是为惩罚错误而人为设计的，它是伯努利似然的负对数。这是第一章"损失函数往往等价于负对数似然"的具体例子。
  • 与最小二乘不同，逻辑回归没有闭式解，只能用迭代法（梯度下降、牛顿法、L-BFGS）。凸性保证迭代一定找到全局最优，但不保证有公式。

小结

逻辑回归的损失是推出来的而不是选出来的：伯努利似然取负对数就是交叉熵，而它的梯度恰好又是"预测减真实"。凸性让这个损失好优化。

  • 感知机 → 逻辑回归：把硬判定换成软概率。代价是失去闭式解，收益是能用极大似然统一解释，并得到置信度。
  • 线性回归 → 逻辑回归：同样是极大似然，只是把标签的分布从高斯换成了伯努利。模型的形式由"输出服从什么分布"决定，而不是由任务名字决定。

注意

  • 三种目标里只有平方误差与交叉熵是从概率假设推出来的；感知机的误分类计数不是——它不连续、不可导，所以没法梯度优化，只能用那个专门的更新规则。
  • 线性回归可以看成"输出层恒等"的广义线性模型，逻辑回归是"输出层 sigmoid"的那一个。这个统一视角在多分类时会自然延伸到 softmax。

小结

线性模型族的共性是"线性得分 + 输出变换 + 与输出分布匹配的损失"。三者的差异全部来自后两项。

机器学习的本质就是用统计和概率模型来描述数据背后的规律，并基于此进行预测；本质的另外一种表达是最小化信息差异（最小化交叉熵），这与其目标函数常常为MLE有关。

有监督学习

有监督学习从带标注的样本 ((x_i, y_i)) 中学习一个从输入 X 到输出 Y 的映射 f。标签 y 就是监督信号：它告诉模型每个样本应有的答案，因此训练过程本质上就是“用预测值 y_hat = f(x) 与真实值 y 作比较，再反过来修正模型”。样本被假设为从某个未知的联合分布 P(X, Y) 中独立同分布采样，真正的目标是让模型在该分布上的期望损失 E[L(f(X), Y)] 最小。但 P(X, Y) 是未知的，实际只能最小化有限训练集上的经验风险（empirical risk），这也是有监督学习容易过拟合、并且通常要在纯 ERM 之外引入正则化（结构风险最小化 SRM）的原因。

训练是一个闭环：前向传播 → 计算损失 → 反向传播梯度 → 用优化器更新参数，如此重复多个 epoch。损失函数需与任务匹配；在给定噪声/模型假设后，它恰好等价于最大似然估计（MLE）导出的负对数似然。

有监督任务通常按标签类型划分：

  • 回归（Regression）：Y 为连续值。模型输出一个实数，使用 MSE、MAE 等连续损失训练。代表算法有线性回归、决策树 / GBDT、神经网络回归器；典型应用是房价、气温、销量预测。

  • 分类（Classification）：Y 为离散类别，涵盖二分类、多分类与多标签；输出层用 sigmoid（标签相互独立）或 softmax（类别互斥）把原始分数 logits 转成概率，并以交叉熵训练。代表算法有逻辑回归、SVM、k-NN、树集成和神经网络；典型应用是垃圾邮件检测、图像识别、情感分析。

标签也不必是标量：序列标注、机器翻译、目标检测这类结构化输出任务同样属于有监督范式。

代表算法既包括传统方法（线性/逻辑回归、SVM、k 近邻、决策树及其集成如随机森林与 GBDT），也包括深度网络（MLP、CNN、RNN、基于 Transformer 的模型）。统一它们的是训练范式而非模型结构：同一个网络既可以被有监督地训练，也可以被无监督地训练。

常见的误区：

  • “有监督”描述的是训练数据/训练范式，而不是模型。 现代深度学习中通常是先在无标注文本或图像上做自监督预训练，再用标签做有监督微调，模型结构始终不变。

  • 标签质量决定了性能上限。 监督信号是唯一携带目标信息的来源，噪声或错误标注会直接压低精度，且无法靠更大的模型完全补偿。

  • i.i.d. 假设会悄悄失效。 有监督学习假设线上数据与训练数据同分布；一旦发生分布偏移（distribution shift）或概念漂移（concept drift），验证集精度便不再能预测线上表现。

无监督学习

无监督学习处理的是没有标签、只有输入 X 的数据。它不预测某个目标，而是去发现数据中的结构：分组、低维表示，或者底层分布 P(X) 的形态。从信息论视角看，有监督学习估计的是条件分布 P(Y|X)，而无监督学习压缩、概括 P(X) 本身——模型完全得不到“对或错”的反馈。

常见的问题族及代表算法：

  • 聚类（Clustering）：把样本划分成组，使组内相似、组间相异。算法有 K-means（基于原型，偏好球形簇）、层次聚类、DBSCAN（基于密度，可处理任意形状与噪声）、高斯混合模型 GMM（软划分/概率化归属）。应用包括客户分群、图像压缩、相关文档归组。

  • 降维与表征学习（Dimensionality reduction & representation learning）：在尽量保留信息的前提下把数据映射到低维空间。线性方法有 PCA / SVD（保留方差最大的方向）；面向可视化的有 t-SNE、UMAP；神经网络方法有自编码器（最小化重构误差）。用途包括特征压缩、去噪、可视化，以及为相似度检索生成嵌入向量。

  • 密度估计与异常检测（Density estimation & anomaly detection）：显式建模 P(X)（如 GMM、核密度估计），落在极低概率区域的点即被判为异常点/离群点。

  • 自监督学习——深度学习时代被模糊的边界。 今天口语中所说的“无监督预训练”通常是自监督：数据本身通过一个预训练任务（pretext task）生成伪标签（如 BERT 的掩码语言模型 MLM、对比学习），再用标准的监督手段训练。它在没有人工标注的情况下学到了表征，但并不属于经典的“发现 P(X) 结构”这一设定——这个区别很容易混淆，也是面试常问的点。

难点与常见误区：

  • 没有真值就没有通用指标。 没有标签意味着“误差”无从定义，模型无法用准确率打分；只能靠内部启发式指标（簇内 SSE、轮廓系数 silhouette、重构误差）、下游任务表现或人工观察来评判——因此无监督结果之间很难客观比较。

  • 聚类结果不是数据的“真实分组”。 划分结果取决于所选的距离度量、特征表示以及聚类数 K 等超参数；同一个数据集按不同目的可以得到多个不同但同样有用的分组——聚类的输出是有用，而非正确。

  • 无监督学习不能凭空创造信息。 它只能揭示数据与所选特征中已经隐含的结构。数据过少或缺乏代表性时，照样会欠拟合或过拟合（例如 K-means 取很大的 K 可以拟合纯噪声）。而且没有标签就无法直接回答预测性问题：要预测某个未见目标，仍需引入标签，这也是无监督方法通常要与后续的有监督或自监督阶段结合的原因。

CNN卷积神经网络

模型识别图像中特定特征的能力不依赖于该特征在图像中的精确位置，这就是CNN的核心设计理念之一：空间不变性 (Spatial Invariance)，也称为平移不变性 (Translation Invariance) 。除此以外，还有局部性，就是指前几层网络的特征的影响范围应该局限于局部而非整体。

卷积神经网络通过两种机制系统化地实现了这种不变性：共享参数的卷积层和汇聚层。

A. 共享参数的卷积层 (Parameter Sharing)

  • 原理： 卷积层（或称检测器/核）在整个输入图像上滑动。无论这个核位于哪个位置，它都使用同一组权重参数。

  • 效果：

    • 实现了不变性： 如果一个 3 * 3 的核学会了识别“垂直边缘”，那么无论这个垂直边缘出现在图像的哪里，这个核都能用相同的权重识别它。

    • 减少参数： 相比于每个图像区域都用一组独立的权重，参数共享极大地减少了需要学习的参数数量。

B. 汇聚层 (Pooling Layer)

  • 原理： 汇聚层通过降采样（如最大池化）来总结一个局部区域内的特征。

  • 效果：

    • 它使得网络对特征的微小平移不那么敏感。即使特征在图像中移动了一两个像素，只要它仍在汇聚窗口内，汇聚层的输出可能保持不变或变化很小。

注意力机制

在描述注意力与视觉的双组件框架中，受试者基于非自主性提示和自主性提示有选择地引导注意力的焦点。非自主性提示是基于环境中物体的突出性和易见性，而受到认知和意识的控制被归为自主性提示。

注意力机制试图用一个“问题”去“搜索”和“提取”最相关的“信息”。假设原始输入特征为 X，通过三个独立的特征矩阵W_Q、K、V投影到三个不同空间，即查询（Query）、K（键）和 V（值）。给定任何查询，注意力机制通过注意力汇聚引导至感官输入（中间特征）。

具体来说，计算Q和K之间的相似度（使用点积）得到注意力分数矩阵E，再归一化转为注意力权重A，最后和V进行加权求和，得到注意力输出Z。KV矩阵存在的意义在于将检索机制和内容提取机制解耦，从而赋予注意力机制强大的动态选择和表达能力。

优化：小批量与 SGD（从数学讲义旧稿迁出）

在深度学习中，由于源数据都比较大，所以通常需要用到批处理。如利用批量来计算梯度的随机梯度法（SGD）就是一个典型应用。深度学习的计算一般比较复杂，并且数据量一般比较大，如果一次处理整个数据，较大概率会出现资源瓶颈。为了更有效地计算，一般将整个数据集分批次处理。过小也无法利用发挥平行处理的优势。因此实际中往往使用mini-batch批量处理。

小批量随机梯度下降SGD，是从数据集中随机抽取的一个小批量，然后根据参数计算损失的梯度，再朝着减少损失的方向更新我们的参数。

评估指标

混淆矩阵：真假表示预测正确还是错误，并非实际为真假。真负例是正确预测的负例，假负例是错误预测为负例实际为正例。

准确率Accuracy是指所有正确分类（无论是正类还是负类）所占的比例，使用(真正率TP+真负率TN)/总样本all，但对于样本类别严重不平衡的情况，如样本中负样本占了99%就可以无脑预测负了，所以针对类别不平衡要使用F1等指标。

精确率Precision指所有正类别分类中实际为正类别的比例，使用真正例TP/(无论真假)预测为正的例TP+TN；如果实际正例的数量非常少（例如总共只有 1-2 个），那么精确率作为一种指标的意义和实用性就会降低。

召回率Recall，又叫真正例率，表示正的中有多少预测准的，使用真正率TP/(无论正负，真正+假阴)实际为正的例TP+FN；适合宁可错不希望漏。相对的，还有假正例率。

假正例越少，精确率越高；假负例越少，召回率越高。因此，精确率和召回率通常呈反比关系，即提高其中一个指标会降低另一个指标。

F1分数，它们的调和平均数，权重各为1；如果倾向于召回率可以改成F1.5、F2分数

损失函数（Error Function）

MSE均方差

均方误差/平方损失（square loss），常用在线性回归模型中来对模型w和b进行求解。均方误差的几何意义对应欧氏距离，基于均方误差最小化求解就是最小二乘法。通常用在连续值预测上，因为在回归问题中，通常假设误差服从正态分布，而 MSE 正是从最大似然估计推导出的最优损失函数。

Cross Entropy交叉熵

交叉熵取自信息论。当我们要搞清楚一件非常非常不确定的事，或是我们一无所知的事情（日食），就需要了解大量的信息。相反，如果我们对某件事已经有了较多的了解，我们不需要太多的信息就能把它搞清楚（如太阳照常升起）。由此引入信息量I，它与概率之间的公式：

I = -log P

为描述一个信息源可能产生的所有信息的平均不确定性。（这个公式之所以使用负对数是因为在计算数据集的似然函数时涉及乘积，而上万的概率相乘会导致计算机数值下溢，负对数保留负相关性的同时将乘积化为加法解决了数值稳定问题。一般选取自然对数以方便求导）

接着便可引入信息论中的熵——香农熵或信息熵，其本质就是在随机事件中信息量的期望：（此处前面乘以P(x)是因为期望的计算是概率×事件）

H(X) = -Σ P(x) log P(x)

抛硬币正反两面概率为0.5，因此得到信息熵为1。若是8个等概率事件，信息熵就是3；而不同概率如{1/2, 1/4, 1/8, 1/16, 1/64, 1/64, 1/64, 1/64}的信息熵为2。可以证明，那些接近确定性的分布（输出几乎可以确定）具有较低的熵，那些接近均匀分布的概率分布具有较高的熵。

交叉熵，是用来衡量两个概率分布P和Q之间的差异。假设有随机变量X，它的真实概率分布为P，而我们在处理实际问题时，使用了一个近似的分布Q来进行拟合。

H(P, Q) = -Σ P(x) log Q(x)

由于使用的是近似分布，所以传递信息需要更多的信息量，因此存在结论：交叉熵一定大于或等于熵。

交叉熵与熵的差称为KL散度，也叫相对熵。在训练网络的场景下，我们可以将近似分布Q看作是网络的实时输出，而我们的目的是通过训练使得Q尽量逼近真实分布，等价于最小化KL散度。网络在使用交叉熵损失函数时需要先用sigmoid函数或者Softmax函数将输出转换为概率值。

激活函数

Softmax（软最大值）

Softmax也常被称为归一化指数函数，作用是将一个包含任意实数值的向量，转换成一个概率分布向量。soft含义是希望分值大的那一项被经常取到，而分值较小的那一项也有一定的概率偶尔被取到。设计的初衷，是希望特征对概率的影响是乘性的。用在多分类这种所有类别之间互斥且穷尽（即样本只可能属于其中一个类别）的场景。

由函数可知，所有概率分布是互斥而非独立的，总和为1，因此有归一化的作用，作用于只选择一个或前几个的情况。

Softmax由于使用指数函数，如果其中某一个特征的值很大，就会导致指数爆炸，分母上溢变为inf，导致 最后得到的是0、inf或nan。这时可以把所有特征都减去这个最大值，即分子分母都除以它，等于exp(Z-argmax(Z))。但有的减去后数值过小，导致下溢为0，指数变为-inf。因此计算y_hat时直接带上外面的log求进行化简。

欠拟合和过拟合

训练误差（training error）是指， 模型在训练数据集上计算得到的误差。 泛化误差（generalization error）是指， 模型应用在同样从原始样本的分布中抽取的无限多数据样本时，模型误差的期望。

如果模型不能降低训练误差，这可能意味着模型过于简单（即表达能力不足）， 无法捕获试图学习的模式。 此外，由于我们的训练和验证误差之间的泛化误差很小， 我们有理由相信可以用一个更复杂的模型降低训练误差。 这种现象被称为欠拟合（underfitting）。

将模型在训练数据上拟合的比在潜在分布中更接近的现象称为过拟合（overfitting）， 即训练误差远小于验证误差。由于不能基于训练误差来估计泛化误差，因此简单地最小化训练误差并不一定意味着泛化误差的减小。

验证集，是在选择一个模型并使用训练集进行训练后，为判断模型是否正确、是否过拟合（估计训练数据的泛化误差）设置的。如果数据稀少，可以使用K折交叉验证。

L2正则化

用于对抗过拟合的技术称为正则化（regularization），当然收集更多数据也可以缓解，但是当数据已经高质量时，可以把重点放在正则化上。

限制特征的数量是缓解过拟合的一种常用技术。仅仅通过简单的限制特征数量（在多项式回归中体现为限制阶数），可能仍然使模型在过简单和过复杂中徘徊， 我们需要一个更细粒度的工具来调整函数的复杂性，使其达到一个合适的平衡位置。

权重衰减（weight decay）是最广泛使用的正则化的技术之一， 它通常也被称为正则化。

对于某个过于复杂、过大的权重向量（使用范数衡量），最常用方法是将其范数作为惩罚项加到最小化损失的问题中。

for epoch in range(num_epochs):
    for x, y_true in zip(x_train, y_train):
        # 前向传播
        hidden_layer = np.maximum(0, np.dot(x, self.weights1) + self.bias1)  # ReLU激活函数
        y_pred = np.dot(hidden_layer, self.weights2) + self.bias2

        # 计算损失和梯度，使用均方误差作为损失函数(Mean Squared Error,MSE)
        # 对于每一个样本，模型预测出来的输出与实际输出之间的差异会被平方，
        # 然后对所有样本的平方差进行求和并除以样本数，即可得到MSE作为模型的损失函数。
        loss = np.square(y_true - y_pred).sum()

        # 下面复杂的方法用来实现反向传播
        # 计算损失函数关于预测输出的导数
        d_loss_pred = -2.0 * (y_true - y_pred)
        # 计算输出层的梯度，
        d_weights2 = np.dot(hidden_layer.reshape(-1, 1), d_loss_pred.reshape(1, -1))
        # 计算输出层偏置的梯度，其值等于输出误差
        d_bias2 = d_loss_pred
        # 计算隐藏层误差，其中 self.weights2.T 代表输出层权重的转置，
        # 计算得到的结果是一个行向量，代表每个隐藏层节点的误差。
        d_hidden = np.dot(d_loss_pred, self.weights2.T)
        # 将隐藏层误差中小于等于 0 的部分置为 0，相当于计算 ReLU 激活函数的导数，
        # 这是因为 ReLU 函数在小于等于 0 的部分导数为 0
        d_hidden[hidden_layer <= 0] = 0  # ReLU激活函数的导数
        # 计算隐藏层权重的梯度，
        # 其中 x.reshape(-1, 1) 代表将输入变为列向量，
        # d_hidden.reshape(1, -1) 代表将隐藏层误差变为行向量，
        # 两者的点积得到的是一个矩阵，
        # 这个矩阵的行表示输入的维度（也就是输入节点的个数），
        # 列表示输出的维度（也就是隐藏层节点的个数），表示每个输入和每个隐藏层节点的权重梯度。
        d_weights1 = np.dot(x.reshape(-1, 1), d_hidden.reshape(1, -1))
        # 计算隐藏层偏置的梯度，其值等于隐藏层误差。
        d_bias1 = d_hidden

        # 更新权重和偏置
        self.weights2 -= learning_rate * d_weights2
        self.bias2 -= learning_rate * d_bias2
        self.weights1 -= learning_rate * d_weights1
        self.bias1 -= learning_rate * d_bias1
